## 변경 원칙

1. 공식 v0.61의 기능과 스키마를 UI보다 우선했습니다.
2. 내부 변수명, 공식 DOM ID, 이벤트 핸들러와 공개 API를 유지했습니다.
3. Provider Manager나 SimCore 전용 provider 기능을 추가하지 않았습니다.
4. 차가운 그래파이트 표면, 작은 반경, 선과 간격 중심의 위계, 제한적인 파란색 강조를 사용했습니다.
5. 카드 중첩과 장식용 배지, 보라색 AI 테마, 넓은 빈 여백을 줄였습니다.
6. 정적 감사 통과와 실제 Risu 검증을 구분했습니다.

## 원본 대비 변경 내역

### 1. 공통 시각 체계와 접근성

- 편집기와 관리 패널의 색상 토큰, 본문·보조·강조 글자 대비를 통일했습니다.
- 입력창, 버튼, 선택 상태, 포커스 표시와 비활성 상태를 공통 규칙으로 정리했습니다.
- 데스크톱과 좁은 화면에서 작업 열이 무너지지 않도록 반응형 1열 전환을 추가했습니다.
- 과도한 둥근 카드 대신 얇은 구분선, 작은 반경과 제한된 작업 폭을 사용했습니다.

### 2. 관리 패널 외곽

#### 현황

- 새 시작 안내와 다음 행동을 2×2 작업 구조로 정리했습니다.
- 엔진 상태 6개 값을 중첩 카드가 아닌 연결된 계기판으로 표시했습니다.
- 연결 상태와 세부 진단을 별도 위계로 나눴습니다.
- 상태 변수 수동 보정의 입력 폭과 표 정렬을 줄여 가로 스크롤 가능성을 낮췄습니다.
- 잠긴 액션은 이유와 연결된 안내가 보이도록 정리했습니다.

#### 설치·작업공간

- 스키마 없음 안내와 현재 캐릭터 설치·제거·불러오기 흐름을 정돈했습니다.
- 첫 설치 01~04 튜토리얼과 닫기 기능을 복원했습니다.
- 생성 실패 시 선택 모델과 실패 이유가 가까이 보이도록 안내를 복원했습니다.
- 패치 계획은 추가·교체·삭제 후보·충돌 요약을 먼저 보여주고, 세부 목록과 적용·되돌리기 행동을 분리했습니다.

#### 세이브

- 파일 내보내기, 파일 가져오기, 채팅 미러 복원을 3열 작업 카드로 나눴습니다.
- 스키마 동봉 복원 옵션을 별도 선택 카드로 분리했습니다.
- 저장 로직과 파일 형식은 공식 구현을 유지했습니다.

#### 도움말

- 공식 개념을 한 턴의 진행 순서와 변수·파생·규칙·액션·AI 설정 순으로 재배치했습니다.
- `int / float / text / bool / enum / list`를 설정·갱신·예시가 구분되는 정적 매뉴얼 카드로 만들었습니다.
- 도움말 안에 임의 이동이나 클릭 동작은 추가하지 않았습니다.

### 3. AI에게 맡기기

- 창작·결과·진단을 탭으로 분리하고 현재 상태와 작업 결과가 섞이지 않게 했습니다.
- 변수와 명령의 전체 생성·교체 도구는 아래 편집 목록과 같은 820px 폭의 단일 카드로 통일했습니다.
- 내보내기와 가져오기를 2열 작업대로 구성하고 모바일에서는 1열로 전환합니다.
- 스트리밍 글자 수처럼 실제 Risu에서 보이지 않던 표시 항목은 제거했습니다.

#### 결과 탭

- `스킨만 / 배치까지`를 떨어진 작은 선택 버튼으로 변경했습니다.
- 디자인 요청을 충분히 적을 수 있도록 textarea를 확대했습니다.
- Hallmark GitHub 링크와 선택형 보정 지침을 추가했습니다.
- Hallmark 옵션은 공식 CSS·배치 생성 프롬프트 본문을 바꾸지 않고, 켰을 때만 보정 지침을 뒤에 추가합니다.
- 만들어진 이벤트는 `추가된 항목 / 발동·조건 / 효과·변수 변경 / 통지`를 분리했습니다.
- 랜덤 이벤트는 `랜덤 · 턴당 N%`처럼 종류와 확률을 텍스트로 명시합니다.

#### 진단 탭

- 도입 문장과 진단 실행 조건을 자연스러운 문장으로 교정했습니다.
- 발견 항목을 중요도별 2열 카드로 배치하고, 고쳐야 하는 문제와 확인 항목을 분리했습니다.
- 깨진 마크다운 기호가 사용자 문장에 노출되지 않도록 표시 계층을 나눴습니다.
- `진단 결과 수정`에서 필요한 항목만 부분 패치로 만들고, 외부 AI용 요청서와 기록용 전체 복사를 분리했습니다.

### 4. JSON 작업대

- 전체 작업본 만들기와 부분 수정 요청서를 같은 높이의 2열 작업 카드로 배치했습니다.
- 전체 스키마 규격 복사 결과를 다시 접을 수 있게 했습니다.
- 패치 붙여넣기, 검사, 반영 전 요약, 전체 작업본 교체와 되돌리기 상태를 구분했습니다.
- JSON 원본 직접 편집과 현재 작업본 복구 경로를 유지했습니다.

### 5. 에셋 팩

- 모드 선택, 자동 감지, 에셋 새로고침과 적용 상태를 상단 작업 영역으로 정리했습니다.
- 토큰 비용 추정은 연결된 3열 표면으로 표시했습니다.
- 팩 설정, 슬롯 설정, 선택 어휘, 폴백과 정렬 행동을 같은 편집 리듬으로 맞췄습니다.
- 빈 팩 상태, 검증 문제와 기존 이미지 지침 가져오기를 분리했습니다.
- 에셋 해석·검증·모델 연결 로직은 변경하지 않았습니다.

### 6. 심층 편집 — 변수

- AI 전체 생성·교체 도구를 단일 카드로 정리했습니다.
- 기본 변수와 파생 변수를 제한된 폭의 카드 목록으로 구성했습니다.
- 표시 이름, ID, 값 형식과 형식별 설정의 오른쪽 정렬선을 맞췄습니다.
- 숫자, 텍스트, ON/OFF, 선택지, 목록마다 필요한 입력만 표시하고 짧은 수치 입력은 폭을 줄였습니다.
- 선택지와 목록은 쉼표가 아니라 한 줄에 하나씩 편집하도록 바꿔 쉼표가 포함된 항목도 보존합니다.
- 참조 중인 ID 변경 경고, 필드별 오류, 상태창 미리보기, 삭제 되돌리기를 추가했습니다.
- 기본 변수와 파생 변수를 함께 확인하는 중복 없는 자동 ID 생성을 추가했습니다.
- 카드 접기·모두 접기·오류만 펼치기를 추가했습니다.
- `⠿` 손잡이 드래그, 고스트 카드, 삽입 위치 강조와 `N번째로 이동` 1.5초 피드백을 추가했습니다.

### 7. 심층 편집 — 명령

- 명령을 연결할 변수를 먼저 고르고 형식에 맞는 명령을 생성하는 흐름으로 정리했습니다.
- 정수·실수·텍스트·ON/OFF·선택지·목록별 실제 사용 예시를 카드 안에 표시합니다.
- 빈 상태, 모두 접기·펼치기, 문제만 펼치기와 명령 추가 후 위치 안내를 추가했습니다.
- 중복 ID, 임시 ID와 목록 합산 판정 때문에 편집 화면이 멈추지 않도록 편집기 측 방어를 추가했습니다.
- 상태창에 명령 목록이 노출되지 않을 때 상태창 탭으로 이동할 수 있는 안내를 추가했습니다.
- ON/OFF 명령의 잘못된 `off` 안내는 엔진 표시 문구 한 곳에서 `0 / false` 안내로 교정했습니다.

### 8. 심층 편집 — 상태창

- 공통 설정을 상태창 제목, 구성 방식, 테마, 접기 허용과 그룹 배치 순으로 정리했습니다.
- 그룹을 요약 헤더와 접을 수 있는 단일 카드로 만들었습니다.
- 항목은 표시할 값, 게이지, 표시 조건, 최대값과 순서 열로 정렬했습니다.
- 게이지 체크 열을 좁히고 항목 사이 간격과 구분선을 조정했습니다.
- 그룹과 내부 항목 모두 `⠿` 드래그, 고스트, 삽입 위치 강조와 1.5초 이동 순번 피드백을 지원합니다.
- 빠진 변수 자동 배치와 접두사 그룹 배치를 보조 작업 영역으로 묶었습니다.
- 디자인 레시피와 커스텀 CSS는 `상태창 꾸미기 (선택)` 아래로 접고 미리보기를 분리했습니다.
- 자동 구성과 커스텀 HTML 템플릿, 조건부 템플릿 기능은 유지했습니다.

## 보호 범위와 코드 영향

- 공식 15개 모듈, 내비게이션 7개, 심층 탭 11개를 유지했습니다.
- 감사 기준의 DOM ID 34개, 핸들러 16개, 핵심 함수 15개, 공개 API 5개가 공식 기준과 일치합니다.
- `expr`, `rng`, `store`, `time`, `validate`, `assets`, `party`, `calendar`, `patch`, `render`, `session`, `diagnose`, `templates` 등 보호 코어는 공식 원본과 동일하게 유지됩니다.
- `engine`은 ON/OFF 명령 도움말 한 문구만 정확히 고정해 교정했고 나머지는 보호됩니다.
- `editor`와 관리 패널의 CSS·마크업·표시 전용 상태가 주 변경 범위입니다.
- 편성표·달력의 `#sc-game` 런타임은 공식 원본과 동일합니다.
- 보조 모델과 생성 모델 호출 어댑터는 공식 원본과 바이트 단위로 동일합니다.

## 아직 완료하지 않은 UI

심층 편집 탭 순서상 `편성표`부터 뒤쪽은 공통 디자인 토큰과 초기 정리만 적용한 초안입니다.

1. 편성표
2. 달력
3. 규칙·이벤트
4. 액션
5. 판정
6. 시간
7. 새 시작
8. AI 설정

이 탭들은 아직 사용자 화면 피드백을 받아 입력 폭, 정보 위계, 접기·정렬과 이동 방식을 탭별로 마무리하지 않았습니다. 다음 버전에서 실제 스키마를 넣은 화면을 기준으로 이어서 수정할 예정입니다.

특히 편성표·달력 편집 UI와 실제 `#sc-game` 패널은 기능 위험이 커서 이번 공개본에서 대규모 재설계를 하지 않았습니다.

## 실기 검증 상태

실제 Risu에서의 전체 회귀 검증은 아직 완료하지 않았습니다. 따라서 정적 검사 통과를 실기 완료로 간주하면 안 됩니다.

우선 확인할 항목:

## 원작자 검토 제안

한 번에 전체를 병합하기보다 다음 순서로 검토하는 편이 안전합니다.

1. 공통 토큰과 접근성 스타일
2. 현황·세이브·도움말 같은 표시 중심 UI
3. 결과 도감과 진단 목록
4. JSON·에셋 작업대
5. 변수·명령·상태창의 편집기 전용 동작
6. ON/OFF 명령 도움말 교정

드래그·되돌리기·부분 패치처럼 상태가 추가된 기능은 실제 Risu 확인 뒤 별도 커밋으로 분리하는 것을 권합니다.
