## 2. 척추 — 챕터 = 시나리오 막

모델은 **지금 챕터의 "원작이라면 이 챕터에 일어날 일"**만 받는다. 다음 챕터 사건은 프롬프트에 없다.
빙의자는 원작을 읽은 사람이지만, 모델이 앞질러 가지 않게 하는 게 우선이다.

| 막 id | 라벨 | 원작이라면 (direct에 실림) | 해금 |
|---|---|---|---|
| `prologue` | 서장 · 빙의 | 눈을 뜬다 — 지금이 원작의 어디쯤인지 파악 | (시작) |
| `debut` | 1장 · 데뷔탕트 | 엘리시아 데뷔, 에르테미안의 호의, 로제타의 질투 | `scn_turns >= 2` |
| `tea` | 2장 · 다과회와 소문 | 다과회 차 사건, 악소문, 남주들이 하나씩 엘리시아와 얽힘 | `cleared >= 1` · minTurns 4 |
| `stairs` | 3장 · 계단과 과자 | 계단 사고 매수, 독 과자, 로제타 고립·가문의 냉대 | `cleared >= 2` · minTurns 4 |
| `night` | 4장 · 파국의 밤 | 저녁 모임, 외진 곳, 칼 — 체포 | `cleared >= 3` · minTurns 4 |
| `verdict` | 5장 · 심판 | 파양·처형 (원작 결말) | `cleared >= 4` |
| `after` | 원작 이후 | 원작이 끝난 세계 — 자유 진행 | `cleared >= 5` |

- `cleared` = 챕터 결판 수. **각 챕터의 절정 갈림길(§4-①)이 결판날 때만** 오른다 — 보조가 못 만진다.
- 절정 갈림길은 `on_stage`(보조가 "그 챕터의 무대에 도착했다"를 기록) **또는 `scn_turns >= N`**(진행 보증)으로 터진다.
  유저가 무도회에 안 가고 버텨도 N턴이면 원작이 찾아온다 — 이게 "원작의 강제력"이다.
- 원작 사건은 **범인이 바뀔 수 있다**: 로제타가 안 하면 다른 누군가가 하고, 로제타가 덮어쓸 수 있다.
  direct 문구: "원작의 이 사건은 어떤 형태로든 일어나려 한다. 누가, 어떻게는 지금까지의 서사가 정한다."

## 3. 퀘스트 라인

목록 변수 `quests` 하나, 항목 머리에 꼬리표.

- **메인** `[1장] 데뷔탕트에서 살아남기` — 막 `onEnter`가 넣고, 절정 갈림길 결판이 지운다. **시스템만** 만진다.
- **서브** `[서브] 안나가 숨기는 것을 알아낸다` — 막 `onEnter`가 1~2개 고정으로 넣고, 서사 속 부탁은 보조가 올린다(상한 5).
  완료되면 보조가 지운다 (desc에 "이뤄졌을 때만, 원문 그대로 지워라").
- 챕터 해금은 메인만 본다 — 서브를 안 해도 이야기는 간다. 서브는 관계 변수로 돌려받는다(보조 기록).

## 4. 강제 선택지 — 두 층

### ① 원작의 순간 (스키마 갈림길, `events[].choices` + `strict: 'last'`)

챕터마다 절정 1개 × pov 2벌. **맨 끝 선택지 = 원작대로** — 안 고르고 보내면 원작대로 흘러간다(최악 규약).

예) 2장 다과회, `pov == "rosetta"`:
1. 차를 엎으려는 하녀의 손목을 잡는다 → doom −10, elicia +10
2. 엘리시아를 다과회에서 빼돌린다 → doom −5, rep −5
3. 직접 사과하고 판을 깬다 → doom −10, rep −10, duke −5
4. 원작대로 한다 → doom +15, rep −10

예) 같은 순간, `pov == "servant"`: 차 쟁반을 내가 받아 든다 / 아가씨를 끌고 나간다 / 차를 쏟는 척 내 옷에 붓는다 / 지켜본다(원작대로).

결판 효과 공통: `cleared + 1`, 메인 퀘스트 remove.

### ② 원작 보정력 (보조가 쓰는 갈림길, `liveChoices`)

평소 장면에서 **원작이 스스로를 되돌리려는 순간**. 보조가 장면에 맞춰 선택지를 즉석에서 쓰고, 태그가 결과를 쥔다.

```
label '원작 보정력', icon '📖'
chance 'doom / 250'            — 원작에 가까울수록 자주 (doom 50 → 20%/턴)
tags   이탈(doom −5) · 타협(doom 0) · 원작(doom +8, worst)
strict 'last'                   — 안 고르면 원작 쪽
```

### (선택) 판정

사교 대결·연기·설득에 `checks` 몇 개 — 선택지 `check`로 붙인다. 1차 구현에선 빼고 시작해도 된다.

## 6. 결말 — 5장 심판

`verdict` 막 진입 시 결말 갈림길. **잠긴 선택지(🔒)가 보인다** — 무엇이 나를 살릴 수 있었는지가 보이게.

- 리칼이 증언한다 — `rical >= 60` (⚠ 2026-09-26 문턱 조정: 리칼 50 · 공작 50 · 황태자 60 → §24)
- 엘리시아가 감싼다 — `elicia >= 60`
- 황태자가 사면을 청한다 — `ert >= 70`
- 공작이 가문의 이름으로 막는다 — `duke >= 60`
- (servant) 내가 대신 죄를 쓴다 — `bond >= 70`
- 도망친다 — 항상
- 받아들인다 — 항상 (원작 결말)

doom이 낮으면(≤ 30) 애초에 심판 자리가 "재판"이 아니라 "해명" 장면으로 바뀐다 (direct 분기).

> 전부 사망은 아니고 시나리오 라인에서 크게 벗어나면 게임오버."

### 게임오버 = 회귀

| 종류 | 조건 (기록된 사실만 — 보조는 심판이 아니다) |
|---|---|
| 사망 | `dead` — 보조가 "유저 캐릭터가 서사에서 죽었다"를 기록. 또는 갈림길 선택지 효과 |
| 원작 확정 | `doom >= 100` — 원작 결말이 되돌릴 수 없게 굳었다 |
| 로제타 사망 | servant 시점 한정 — 지킬 대상이 먼저 죽었다 |
| 이탈 | 면접 탈락처럼 **챕터 자체가 성립하지 않는** 결판 (갈림길의 특정 선택지·판정 등급이 직접 세운다) |

"크게 벗어났다"를 보조가 판단하게 하지 않는다 — 게임오버는 **갈림길·판정·명백한 사실(사망)**에서만 난다.
평소의 자잘한 이탈은 doom으로 쌓이고, 쌓인 doom이 100이 되면 그때 게임오버.

### 회귀하면

- **체크포인트 = 챕터 시작.** 막 `onEnter`가 저장, 게임오버가 되감는다.
- 되감기는 것: 관계·평판·doom·건강·퀘스트·위치·**날짜·현재 막**
- 남는 것 (회귀자의 기억): `loop`(회귀 횟수) · `memories`(목록 — "3장 과자에 독이 있다" 같은 것, 보조가 회귀 직전 서사에서 적는다) · 열린 비밀(`sec_*`)
- 회귀 직후 장면: "눈을 뜨면 다시 그 아침" — 챕터 첫 장면 + `[회귀 N회차]` 통지 + 기억 목록.

### 플러그인 v1.11.0 체크포인트 (2026-09-25 구현, feat/checkpoint)

v1.10까지는 되감기가 안 됐다 — 효과(`set`)는 스키마 vars만 대상이라 예약 키 `time_epoch`(날짜)·`scn_idx`(현재 막)를
못 돌리고, 막은 앞으로만 가고, 시간은 음수 skip을 무시한다. 그래서 코어 기능으로 넣었다 (`core/checkpoint.js`, 스킬 schema.md "checkpoint" 절).

```
막 onEnter:        [{ "checkpoint": "save" }]
게임오버 이벤트:     [{ "set": "loop", "expr": "loop + 1" }, { "checkpoint": "load" }]
최상위:             "checkpoint": { "keep": ["loop", "memories"], "notify": "[회귀 {loop}회차] 눈을 뜨면 다시 그 아침이다." }
```
- 되감기 = 변수 전부(날짜·막 포함) + 이벤트 once 기록. 남는 것 = keep + 열린 비밀. 턴 번호·채팅은 앞으로만.
- 선택지로 되감으면 **고른 그 턴**에 "눈을 뜨면 그 아침" 장면이 나가고, 이벤트로 되감으면 다음 턴.
- 회귀물·로그라이크·타임루프 공용 — 이 봇 전용이 아니다.

### 서장 = 시종 면접 (servant 시점) — ⚠ 2026-09-26 걷힘: 첫 출근 날로 바꿨다 (§22)

- **면접 전 — 빙의 자각** [유저 2026-09-26 "퍼메가 없으니 애매 — 빙의한 거 눈치채고 지금 상황 파악하고 면접 보러 가야"]: 2/24 07:00 수도 외곽 셋방에서 눈을 뜬다. 퀘스트 `[서장] 이 몸이 누구인지, 지금이 언제인지 알아낸다` + 지시문 `[빙의 직후]`(방 안의 단서·기억 조각·거리의 소문으로 한 장면씩). 보조가 `iv_ready`(공작저 도착)를 적으면 다음 응답부터 질문, 셋방에서 5턴 머물면 `iv_call` "[면접 시각]"이 도착까지 그리게 한다(질문은 그다음 응답). 회귀하면 셋방으로 돌아가고, 기억이 있는 유저는 곧장 공작저로 갈 수 있다. 몸의 신상(이름·경력)은 페르소나 몫 — 보조 모델엔 페르소나가 안 가므로 스키마는 "지원자" 자리만 안다. 범용 페르소나 예: 노엘 그레이(20, 평민, 5년 차 하인, 추천서, 원작에 없음, 기억은 조각만) [유저]
- 메인 퀘스트 `[서장] 로제타의 시종 면접에 합격하라`
- 면접 = 로제타의 질문 3개. 질문마다 `liveChoices`(보조가 로제타 성격에 맞춰 답변지를 쓴다) — 태그 `정답`·`무난`·`실언`(worst)
- 3문항 뒤 점수로 결판 — 합격이면 1장으로, 탈락이면 게임오버(첫 회귀). 첫 판에 떨어지는 게 오히려 장르의 맛.
- 빙의 대상: ~~원작 3장 독 과자를 먼저 맛보고 죽은 시녀~~ — 기각 (2026-09-25 유저 "별로"). 원작 3장 독 과자는 엘리시아가 눈치채고 안 먹는 사건이라 원작과도 어긋나는 창작이었다.
  → **페르소나에 맡긴다** (2026-09-25 유저 결정, "애초에 새로 뽑는 것부터 시작하니까"). 스키마는 "로제타 전속 시종 지원자"라는
  자리만 안다 — 이름·성별·출신·사연은 페르소나. 원작 속 운명 설정은 두지 않는다(면접에서 새로 뽑히는 사람이라 원작에 자리가 없다).

## 13. 길이 — 얼마나 길게 잡나

원본에 스토리 라인이라 할 만한 건 원작 타임라인 4막뿐이고, 인물 26명은 전부 "설정"이지 "사건"이 아니다.

- **척추는 짧게**: 서장(면접) + 원작 4장 + 심판 = 6막. 챕터당 15~25턴(minTurns 바닥 + `scn_turns` 백스톱) → 한 바퀴 100~150턴.
  회귀가 판을 늘려 주므로 척추를 늘릴 필요가 없다.
- **인물은 사건이 아니라 재료로**: 챕터마다 무대 캐스트 3~5명만 direct에 올린다. 나머지 인물은 서브 퀘스트(각 인물의 Goal·Dream·Secret이 씨앗)와 랜덤 이벤트로 등장.
  26명 각자의 줄거리를 쓰지 않는다.
- **원작 이후(2부)는 나중에**: 막은 끝에 덧붙이면 옛 세이브가 안 깨진다(`scn_idx`는 번호) — 중간 삽입은 깨진다. **덧붙이기 전용**으로 운용.
- **첫 구현은 서장 + 1장까지**만 만들어 실기 → 길이·페이스 감을 잡고 늘린다.

1. **각성** — 심판을 넘긴 뒤, 로제타의 권능이 드러난다(비밀 `power` 전모). 신성력·마력을 지우는 힘이라 신전과 마탑이 동시에 주목.

3. **고해 장부** — 대신관 부패와 알드릭의 장부. 장부에 로제타(또는 공작가)의 이름이 있다. 디안느와 손잡을지, 알드릭과 거래할지.
4. **황궁** — 이슈트반이 떠난 이유, 드미트리샤, 유온의 이중 장부. 제국 정치의 한복판.
5. **어머니** — 로제타의 출생. ⚠ 원본이 완전히 비워 둔 칸이다. 채울지, 누가 채울지(스키마 비밀 vs 서사 즉흥) 유저 결정.

- 막은 **덧붙이기 전용**(§13)이라 1부를 먼저 굴린 뒤 붙여도 세이브가 안 깨진다.

## 15. 2부 구조 — 줄기 + 무대 뒤 (2026-09-25 유저 방향)

> "2부부터는 진영마다 정해 놓기 어려우니 유저가 특정 조건을 달성할 때마다 서브 퀘스트 줄기로 열리게.
> 언제 진행해도 큰 문제없는 줄기만 정해 두고. 스토리는 유저만 움직인다고 되는 게 아니니까, 아웃풋에 안 나와도
> 밑작업·NPC들이 움직이다가 표면으로 나올 때 이벤트가 터지게."

1부 = 원작 타임라인(선형 막, 확정). 2부 = 막 대신 **진영별 두 층**:

### (a) 줄기 — 유저가 여는 서브 퀘스트 라인
- 진영마다 단계 변수 하나(`ql_temple` 0~N). 여는 조건 = 유저가 달성한 것(인물과의 접점·호감·단서). 단계는 갈림길·기록된 사실로만 오른다.
- 지시문은 **지금 단계 하나만** 싣는다(`when: ql_temple == 2`) — 다음 단계는 모델이 모른다(시나리오와 같은 은닉).
- **순서 무관 규칙** (어느 시점에 해도 되게): ① 줄기는 자기 단계와 공용 상태(평판·권능·날짜)만 조건으로 읽는다
  ② 다른 줄기의 결과는 **양념으로만** 읽는다(있으면 대사 한 줄, 없어도 성립) ③ 한 줄기가 다른 줄기에 필요한 인물을 없애지 않는다 —
  없앤다면 그 줄기에 대체 경로를 둔다.

### (b) 무대 뒤 — 유저가 안 봐도 흐르는 진영 시계
- 진영마다 숨은 시계(`fr_temple` 0~100). **작중 시간**으로 흐른다(onTurn `+ turn_day * 속도` — 대화만 한 턴은 0, "한 달 뒤"는 한 달치).
  보조 AI는 못 만진다(allow 밖). 유저가 그 줄기에 개입하면 갈림길 효과가 시계를 늦추거나 되돌린다.
- 문턱마다 세 겹: **낌새**(비밀 1단계 — 이유 없는 징후만 모델에게: "신전 구호소가 자주 닫힌다") → **표면화 이벤트**(once — 통지로 사건이
  터진다: "성녀 이단 심문 공고") → **결과**(되돌릴 수 없는 세계 변화 플래그, 다른 줄기가 양념으로 읽는다).
- 그 사이의 밑작업은 비밀 단계 text로 — 표면화 순간 "그동안 무대 뒤에서 벌어진 일"이 열려 모델이 앞뒤를 맞춰 쓴다.
- 1부의 "원작 보정력"(doom)도 같은 기계 — 원작이라는 진영의 시계다.

### 플러그인 v1.12.0 무대 뒤 (2026-09-25 구현, 유저 "어차피 할 거면 정식안")

## 16. 호감도 — 성별 무관, 이야기·결말에 걸린 인물만 (2026-09-25 유저 결정)

> "스토리와 엔딩에 관계된 주요인물만 호감도를 만들고, 게이플·백합·노말은 알아서 정하라고. 성별은 고정할 수 있는 부분이 아니고 여캐도 다양하니."

- "남주 호감"을 없앤다. 호감은 **관계의 거리**(0~100) 하나 — 우정·충성·연애 중 무엇으로 자라는지는 **유저의 페르소나와 행동**이 정한다.
  지시문 한 줄: "관계가 어디로 자랄지는 유저가 정한다. 인물의 성별로 연애 여부를 짐작하지 마라."
- 칸을 두는 기준 = **줄기의 문을 열거나 결말 선택지를 여는 인물**. 그 밖의 인물은 `ties`(숫자 없는 관계 메모).
- 1부 (원작 구간 · 심판 결말에 걸림): 로제타(시종 시점 — 로제타 시점에선 없음) · 엘리시아 · 에르테미안 · 리칼 · 카르디온 공작 · 안나
- 2부 (진영 줄기 열쇠 — 2부를 만들 때 붙인다): 디안느·알드릭(신전) · 도리스(뒷골목) · 클레네(실버버그) · 이슈트반·드미트리샤·유온(황궁) · 에크시온·레아(마탑)
- 인물이 많아도 비용은 낱말 게이트(`updater.allow[].mentions`)로 막는다 — 보조는 그 인물이 등장한 턴에만 그 칸을 본다.
- ⚠ 드미트리샤(17)·엘시(16)는 설정상 미성년 — 호감 칸은 두되(줄기 열쇠) 관계는 우정·보호로만. 지시문으로 못 박는다.

전에는 결말이 2부 지시문의 `{ending}` 한 단어로만 이어졌고, 진영 줄기 다섯은 결말을 읽지 않았다. 이제 결말 하나 = **시작 장소 · 처지 · 첫 퀘스트 · 먼저 열리는 줄기**.
꼬리표: **[원본]** 인물 씨앗(리칼: 권능을 실은 검·칼끝이 무뎌지는 두려움 / 에르테미안: 제국의 부흥과 가족의 화목 / 클레네: 사교계 정상) / **[초안]** 입구·장소·문구.

| 결말 | 시작 장소 | 먼저 열리는 줄기 — 입구 [초안] |
|---|---|---|
| 리칼의 증언 | 카르디온 공작저 | 마탑 — 리칼의 검에 실린 권능이 로제타 곁에서 꺼지는 걸 마탑이 본다 |
| 엘리시아의 변호 | 에버렛 후작저 | 황궁 — 엘리시아의 손님으로 황궁 연회에 |
| 황태자의 재심 청원 | 황궁 동쪽 별관 | 황궁 — 판결까지 별관에 머문다(보호이자 감시) |
| 공작의 이름 | 카르디온 공작저 | 신전 — 알드릭의 고해 장부에 카르디온가의 이름(§19 창작 연결) |
| 스스로 밝힌 결백 | 카르디온 공작저 | 실버버그 — 사교계 쪽 입구, 클레네의 초대 |
| 대신 진 죄 (시종·빙의자) | 실버버그 영지의 광산 마을 | 실버버그 — 광산 쪽 입구, 추방된 유저와 수도에 남은 로제타의 거리 |

- 지시문 `am_<결말>` = `[결말의 여파 · …]` 처지 — 먼저 열린 줄기가 결판(`ql ≥ 3`)날 때까지.

## 24. 서브 완료 — 리칼·공작·황태자로 가는 길 (2026-09-26, 유저 (가))

심판의 잠긴 선택지 넷 중 셋(리칼·공작·황태자)은 선택지로 호감을 올릴 곳이 거의 없어, 보조의 평소 기록에만 기대 사실상 닫혀 있었다.

## 25. 마석 중독 · 권능의 증명 · 몸 (2026-09-26, 유저 ㄱ·ㄴ·ㄷ)

## 26. 에필로그 — 2부를 맺는다 (2026-09-26, 유저 (다))

2부(원작 이후)는 줄기 다섯이 저마다 결판·놓침으로 끝나지만, 이야기 전체를 닫는 자리가 없었다. 이제 **매듭이 셋 이상이면 시스템이 맺을지 묻는다.**
꼬리표: **[유저]** 구조(줄기 결과를 모아 2부를 닫는다) / **[초안]** 문턱·제목·문구.

- **매듭** = 줄기가 결판(3·4·5)났거나 놓쳤다(9) — 파생 `settled`(좋게 맺음 `good_n` = 3의 수, 놓침 `lost_n` = 9의 수).
- **제안** `epi_offer`(갈림길, 1턴 안 고르면 맨 끝): 매듭 ≥ 3이면 "이야기를 맺는다 — 에필로그로" / "아직 — 남은 일을 더 본다"(맨 끝). "아직"이면 그때 매듭 수(`epi_later`)를 적어 두고, 매듭이 하나 더 늘면 다시 묻는다.
- **에필로그 막** `epilogue`(여덟째 막, `epi_go`로 해금, 진입 저장): 줄기·결말 퀘스트를 걷고 통지 `[시스템] 모든 임무 종료.`
  막 지시 = 제목 · 결말 · 가까워진 사람(호감 50↑, 파생 `close_people`) · "계절이 한 번 바뀐 뒤, 인물마다 짧은 장면, 마지막은 로제타의 얼굴" · 그 뒤로는 자유롭게.
  줄기 결과 줄(§19 results)은 그대로 실리고, 매듭 못 지은 줄기는 단계 지시 없이 `[에필로그 · 남은 일]`로만 스친다. 로제타 시점 밖이면 `[에필로그 · 곁]`(신뢰 → 가장 가까운 사람 / 곁을 지키는 사람 / 아직 거리가 있는 사람), 병의 정체를 알면 `[에필로그 · 마석]`.
- **제목** [초안] `epi_title`: 좋게 맺은 줄기 셋↑ + 마석 끊음 = **원작 밖의 봄** · 좋게 셋↑ = **새로 쓴 이야기** · 놓침 셋↑ = **살아남은 자의 겨울** · 그 밖 = **악녀의 다음 장**. 상태창 진행 줄에 뜬다.
- 에필로그가 새 막이 되며 "원작 이후가 아니면" 조건이 에필로그에서 되살아나지 않게 고쳤다: 원작의 흐름 시계·원작 보정력 = `cleared < 5`, 금단 장면은 에필로그에서 멈춤, 추방 판정 = `cleared >= 5`, 줄기 진상·결판·단계 지시 = `scn_act == "after"`에서만. 장 번호 파생 `chapter` = 에필로그 7.
- 자체 시험 166 → 179.

## 27. 수련은 자유 시간에만 (2026-09-26, 유저 "서사적으로 불가능한데 누르면? 자유시간에만 열린다고 해야 하나")
