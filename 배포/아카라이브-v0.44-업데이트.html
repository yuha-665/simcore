SimCore는 봇에 숫자로 굴러가는 상태를 붙여 주는 플러그인입니다. 식량·호감도·재정 같은 걸 AI에게 세라고 시키는 대신 시스템이 직접 계산하고, 그 결과를 상태창과 프롬프트로 내보냅니다.

이번 업데이트를 한 줄로

봇 고치는 일도 AI에게 맡깁니다 — 통짜 재생성 없이, 바꿀 부분만.

만드는 건 원래 됐습니다(규격 내보내기). 문제는 그 다음이었어요 — 이벤트 하나 넣자고 스키마 전체를 다시 받아 통째로 갈아끼우는 건, 잘 되던 부분까지 걸고 하는 도박이니까요. 이제 그거 안 해도 됩니다.

v0.44 AI에게 스키마 고치게 하기 — 왕복 패치

지금까지 봇을 굴리다가 "산적 습격 이벤트 하나만 넣고 싶은데" 싶으면 방법이 둘뿐이었습니다. 스키마 문법을 배워서 손으로 넣거나, AI에게 전체를 다시 만들게 하거나. 전자는 어렵고 후자는 멀쩡하던 부분까지 AI가 다시 쓰면서 망가뜨립니다.

이제 봇 편집 → JSON 탭에 ② AI에게 스키마 고치게 하기가 생겼습니다. 흐름은 ①(만들게 하기)과 똑같이 복사-붙여넣기 왕복인데, 오가는 게 통짜가 아니라 패치입니다. 

① [수정 요청 규격 복사] 누르고 → AI 채팅에 붙여넣고 → 원하는 걸 말합니다
   "산적 습격 이벤트 추가해줘. 경계가 5 이상이면 발동, 금화를 뺏기게"

② AI가 바꿀 부분만 담은 패치를 줍니다 — 스키마 전체가 아니라 이만큼만
   { "add": { "vars":   [ 산적 경계 변수 ],
              "events": [ 산적 습격 이벤트 ] } }

③ 붙여넣고 [🔍 패치 검사] → 뭐가 어떻게 되는지 보여주고 → [✅ 패치 적용]
   계획: 추가 2 · 교체 0 · 삭제 후보 0 · 충돌 0
   ＋ 변수 `raid_alert` 산적 경계
   ＋ 이벤트 `bandit_raid` Bandits raid the village.

복사되는 규격에는 지금 봇에 있는 변수·이벤트·액션 목록이 같이 실려 갑니다. 그래서 AI가 없는 변수를 지어내지 않고, 있는 것과 이름이 겹치는 것도 대부분 알아서 피합니다. 상태창 꾸밈(CSS)은 안 실어서 통짜 규격서보다 오히려 가볍습니다.

AI가 실수하면? — 그래서 안전장치가 셋입니다

1. 겹치면 멈춥니다. 나중에 다른 채팅에서 "딴 것도 만들어줘" 하면, AI는 지난번 패치를 모르니 우연히 같은 id를 또 만들 수 있습니다. 이때 기존 걸 조용히 덮어쓰는 게 아니라 멈추고 물어봅니다 — 기존을 교체할지, 새 이름으로 나란히 추가할지, 건너뛸지. 새 이름을 고르면 패치 안에서 그 이름을 쓰는 식·효과까지 전부 따라 바뀝니다. 

⚠ 충돌: 이벤트 'bandit_raid'가 이미 있음   [건너뛰기 (기본) ▾]
   기존: 산적이 들이닥쳤다! ↔ 새것: 산적 두목의 복수
   — 이름이 달라 서로 다른 항목일 가능성이 높습니다

2. 삭제는 기본 꺼짐. AI가 시키지도 않았는데 "정리"랍시고 삭제를 끼워 넣는 일이 있습니다. 삭제 후보는 체크박스로 나오고 기본 해제라, 직접 체크한 것만 지워집니다.

3. 전부 아니면 전무. 패치의 어느 한 조각이라도 검증을 못 넘으면 아무것도 적용되지 않습니다. 이벤트는 들어갔는데 그 이벤트가 쓰는 변수는 빠진, 반쯤 망가진 상태가 생길 수 없습니다. 적용된 뒤에도 [↩ 되돌리기]가 한 번 남아 있고요.

v0.44.1 실전에서 바로 나온 보정 셋

올리기 전에 등장인물 9명짜리 봇을 이 기능으로 직접 개조해 봤는데, 바로 세 가지가 걸렸습니다.

1. 경고 147줄 사태. 인물마다 호감·기분·위치 변수를 두고 이름을 걸었더니, 검증기가 "같은 낱말을 같이 씁니다"를 조합마다 한 줄씩 쏟아냈습니다. 이제 한 인물의 변수 묶음은 묶음당 한 줄로 접고 ("묶음이면 정상"이라고 알려줌), 진짜 문제 — 한 낱말이 서로 다른 인물의 변수까지 여는 경우 — 만 경고합니다. 덤으로 경고가 4건을 넘으면 접혀서, 경고 벽에 오류가 파묻히는 일도 없습니다.

2. 상태창 손조립 노가다. 인물 8명 × 수치 6개면 그룹 8개에 항목 48개를 손으로 끼워야 했습니다. 상태창 탭에 [⚡ 접두사로 그룹 묶어 배치]가 생겼습니다 — 변수 id가 noz_호감·noz_기분처럼 접두사를 공유하면 인물별 그룹을 자동으로 만들어 넣습니다 (제목도 라벨에서 따오고, 기본 접힘).

3. AI가 update를 겁내는 문제. 규격에 기존 항목의 id만 실려 가니, AI가 "본문을 모르니 update하면 날아가겠지"라며 삭제+재추가로 우회하다 검사에서 막혔습니다. 이제 이벤트·액션 등의 전문이 규격에 같이 실려 AI가 보고 고쳐 쓰고, 우회 금지도 규격에 못박았습니다.

봇 만드시는 분께

쓰던 봇은 아무것도 안 바뀝니다. 새 섹션이 하나 생겼을 뿐이고, 기존 ①(통짜 만들기)·탭별 내보내기·JSON 직접 편집은 전부 그대로입니다.

상대 AI는 아무거나 됩니다 — ChatGPT든 클로드든 제미나이든, 규격을 읽고 JSON을 뱉을 수 있으면 끝. 받아온 패치가 이상하면 검사 단계에서 걸리고, 걸린 문구를 그대로 AI에게 돌려주면 고쳐 옵니다. "상태창(statusUI)은 패치로 못 다룹니다"라고 나오면 그건 사양입니다 — 상태창 꾸밈은 지금처럼 상태창 탭에서 하세요.
