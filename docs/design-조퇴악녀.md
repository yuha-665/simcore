## 2. 척추 — 챕터 = 시나리오 막

모델은 **지금 챕터의 "원작이라면 이 챕터에 일어날 일"**만 받는다. 다음 챕터 사건은 프롬프트에 없다.
빙의자는 원작을 읽은 사람이지만, 모델이 앞질러 가지 않게 하는 게 우선이다.

| 막 id | 라벨 | 원작이라면 (direct에 실림) | 해금 |
|---|---|---|---|
| `prologue` | 서장 · 빙의 | 눈을 뜬다 — 지금이 원작의 어디쯤인지 파악 | (시작) |
| `debut` | 1장 · 데뷔탕트 | 엘리시아 데뷔, 에르테미안의 호의, 로제타의 질투 | `scn_turns >= 2` |
| `tea` | 2장 · 다과회와 소문 | 다과회 차 사건, 악소문, 남주들이 하나씩 엘리시아와 얽힘 | `cleared >= 1` · minTurns 4 |
| `stairs` | 3장 · 계단과 과자 | 계단 사고 매수, 독 과자, 로제타 고립·가문의 냉대 | `cleared >= 2` · minTurns 4 |
| `night` | 4장 · 파국의 밤 | 저녁 모임, 외진 곳, 칼 — 체포 | `cleared >= 3` · minTurns 4 |
| `verdict` | 5장 · 심판 | 파양·처형 (원작 결말) | `cleared >= 4` |
| `after` | 원작 이후 | 원작이 끝난 세계 — 자유 진행 | `cleared >= 5` |

- `cleared` = 챕터 결판 수. **각 챕터의 절정 갈림길(§4-①)이 결판날 때만** 오른다 — 보조가 못 만진다.
- 절정 갈림길은 `on_stage`(보조가 "그 챕터의 무대에 도착했다"를 기록) **또는 `scn_turns >= N`**(진행 보증)으로 터진다.
  유저가 무도회에 안 가고 버텨도 N턴이면 원작이 찾아온다 — 이게 "원작의 강제력"이다.
- 원작 사건은 **범인이 바뀔 수 있다**: 로제타가 안 하면 다른 누군가가 하고, 로제타가 덮어쓸 수 있다.
  direct 문구: "원작의 이 사건은 어떤 형태로든 일어나려 한다. 누가, 어떻게는 지금까지의 서사가 정한다."

## 3. 퀘스트 라인

목록 변수 `quests` 하나, 항목 머리에 꼬리표.

- **메인** `[1장] 데뷔탕트에서 살아남기` — 막 `onEnter`가 넣고, 절정 갈림길 결판이 지운다. **시스템만** 만진다.
- **서브** `[서브] 안나가 숨기는 것을 알아낸다` — 막 `onEnter`가 1~2개 고정으로 넣고, 서사 속 부탁은 보조가 올린다(상한 5).
  완료되면 보조가 지운다 (desc에 "이뤄졌을 때만, 원문 그대로 지워라").
- 챕터 해금은 메인만 본다 — 서브를 안 해도 이야기는 간다. 서브는 관계 변수로 돌려받는다(보조 기록).

## 4. 강제 선택지 — 두 층

### ① 원작의 순간 (스키마 갈림길, `events[].choices` + `strict: 'last'`)

챕터마다 절정 1개 × pov 2벌. **맨 끝 선택지 = 원작대로** — 안 고르고 보내면 원작대로 흘러간다(최악 규약).

예) 2장 다과회, `pov == "rosetta"`:
1. 차를 엎으려는 하녀의 손목을 잡는다 → doom −10, elicia +10
2. 엘리시아를 다과회에서 빼돌린다 → doom −5, rep −5
3. 직접 사과하고 판을 깬다 → doom −10, rep −10, duke −5
4. 원작대로 한다 → doom +15, rep −10

예) 같은 순간, `pov == "servant"`: 차 쟁반을 내가 받아 든다 / 아가씨를 끌고 나간다 / 차를 쏟는 척 내 옷에 붓는다 / 지켜본다(원작대로).

결판 효과 공통: `cleared + 1`, 메인 퀘스트 remove.

### ② 원작 보정력 (보조가 쓰는 갈림길, `liveChoices`)

평소 장면에서 **원작이 스스로를 되돌리려는 순간**. 보조가 장면에 맞춰 선택지를 즉석에서 쓰고, 태그가 결과를 쥔다.

```
label '원작 보정력', icon '📖'
chance 'doom / 250'            — 원작에 가까울수록 자주 (doom 50 → 20%/턴)
tags   이탈(doom −5) · 타협(doom 0) · 원작(doom +8, worst)
strict 'last'                   — 안 고르면 원작 쪽
```

### (선택) 판정

사교 대결·연기·설득에 `checks` 몇 개 — 선택지 `check`로 붙인다. 1차 구현에선 빼고 시작해도 된다.

## 6. 결말 — 5장 심판

`verdict` 막 진입 시 결말 갈림길. **잠긴 선택지(🔒)가 보인다** — 무엇이 나를 살릴 수 있었는지가 보이게.

- 리칼이 증언한다 — `rical >= 60`
- 엘리시아가 감싼다 — `elicia >= 60`
- 황태자가 사면을 청한다 — `ert >= 70`
- 공작이 가문의 이름으로 막는다 — `duke >= 60`
- (servant) 내가 대신 죄를 쓴다 — `bond >= 70`
- 도망친다 — 항상
- 받아들인다 — 항상 (원작 결말)

doom이 낮으면(≤ 30) 애초에 심판 자리가 "재판"이 아니라 "해명" 장면으로 바뀐다 (direct 분기).

> 전부 사망은 아니고 시나리오 라인에서 크게 벗어나면 게임오버."

### 게임오버 = 회귀

| 종류 | 조건 (기록된 사실만 — 보조는 심판이 아니다) |
|---|---|
| 사망 | `dead` — 보조가 "유저 캐릭터가 서사에서 죽었다"를 기록. 또는 갈림길 선택지 효과 |
| 원작 확정 | `doom >= 100` — 원작 결말이 되돌릴 수 없게 굳었다 |
| 로제타 사망 | servant 시점 한정 — 지킬 대상이 먼저 죽었다 |
| 이탈 | 면접 탈락처럼 **챕터 자체가 성립하지 않는** 결판 (갈림길의 특정 선택지·판정 등급이 직접 세운다) |

"크게 벗어났다"를 보조가 판단하게 하지 않는다 — 게임오버는 **갈림길·판정·명백한 사실(사망)**에서만 난다.
평소의 자잘한 이탈은 doom으로 쌓이고, 쌓인 doom이 100이 되면 그때 게임오버.

### 회귀하면

- **체크포인트 = 챕터 시작.** 막 `onEnter`가 저장, 게임오버가 되감는다.
- 되감기는 것: 관계·평판·doom·건강·퀘스트·위치·**날짜·현재 막**
- 남는 것 (회귀자의 기억): `loop`(회귀 횟수) · `memories`(목록 — "3장 과자에 독이 있다" 같은 것, 보조가 회귀 직전 서사에서 적는다) · 열린 비밀(`sec_*`)
- 회귀 직후 장면: "눈을 뜨면 다시 그 아침" — 챕터 첫 장면 + `[회귀 N회차]` 통지 + 기억 목록.

### 플러그인 v1.11.0 체크포인트 (2026-09-25 구현, feat/checkpoint)

v1.10까지는 되감기가 안 됐다 — 효과(`set`)는 스키마 vars만 대상이라 예약 키 `time_epoch`(날짜)·`scn_idx`(현재 막)를
못 돌리고, 막은 앞으로만 가고, 시간은 음수 skip을 무시한다. 그래서 코어 기능으로 넣었다 (`core/checkpoint.js`, 스킬 schema.md "checkpoint" 절).

```
막 onEnter:        [{ "checkpoint": "save" }]
게임오버 이벤트:     [{ "set": "loop", "expr": "loop + 1" }, { "checkpoint": "load" }]
최상위:             "checkpoint": { "keep": ["loop", "memories"], "notify": "[회귀 {loop}회차] 눈을 뜨면 다시 그 아침이다." }
```
- 되감기 = 변수 전부(날짜·막 포함) + 이벤트 once 기록. 남는 것 = keep + 열린 비밀. 턴 번호·채팅은 앞으로만.
- 선택지로 되감으면 **고른 그 턴**에 "눈을 뜨면 그 아침" 장면이 나가고, 이벤트로 되감으면 다음 턴.
- 회귀물·로그라이크·타임루프 공용 — 이 봇 전용이 아니다.

### 서장 = 시종 면접 (servant 시점)

- 메인 퀘스트 `[서장] 로제타의 시종 면접에 합격하라`
- 면접 = 로제타의 질문 3개. 질문마다 `liveChoices`(보조가 로제타 성격에 맞춰 답변지를 쓴다) — 태그 `정답`·`무난`·`실언`(worst)
- 3문항 뒤 점수로 결판 — 합격이면 1장으로, 탈락이면 게임오버(첫 회귀). 첫 판에 떨어지는 게 오히려 장르의 맛.
- 빙의 대상 후보: **원작 3장 독 과자를 먼저 맛보고 죽은 시녀** — 원작에 한 줄 나오는 엑스트라. 로제타를 살리는 게 곧 내가 사는 길이 된다.

## 13. 길이 — 얼마나 길게 잡나

원본에 스토리 라인이라 할 만한 건 원작 타임라인 4막뿐이고, 인물 26명은 전부 "설정"이지 "사건"이 아니다.

- **척추는 짧게**: 서장(면접) + 원작 4장 + 심판 = 6막. 챕터당 15~25턴(minTurns 바닥 + `scn_turns` 백스톱) → 한 바퀴 100~150턴.
  회귀가 판을 늘려 주므로 척추를 늘릴 필요가 없다.
- **인물은 사건이 아니라 재료로**: 챕터마다 무대 캐스트 3~5명만 direct에 올린다. 나머지 인물은 서브 퀘스트(각 인물의 Goal·Dream·Secret이 씨앗)와 랜덤 이벤트로 등장.
  26명 각자의 줄거리를 쓰지 않는다.
- **원작 이후(2부)는 나중에**: 막은 끝에 덧붙이면 옛 세이브가 안 깨진다(`scn_idx`는 번호) — 중간 삽입은 깨진다. **덧붙이기 전용**으로 운용.
- **첫 구현은 서장 + 1장까지**만 만들어 실기 → 길이·페이스 감을 잡고 늘린다.
