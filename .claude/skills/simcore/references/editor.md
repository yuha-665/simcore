# 편집기 UI 레퍼런스

`createSchemaEditor()` — 봇 편집 화면. 가이드/패치글을 쓸 때 **버튼 이름을 여기서 확인할 것.**
틀린 라벨은 가이드를 못 쓰게 만든다.

## 탭 구성 (`TABS`)

|---|---|

## 패널 쪽 페이지 (봇 편집 밖)

| 페이지 | 주요 버튼 |
|---|---|
| **새 시작** | 프리셋 버튼들 · `상태 완전 초기화 (스냅샷 삭제)` · `보조 모델 연결 테스트` · 상태 변수(수동 보정) · 액션 무장 |
| **봇 편집** | `현재 캐릭터에 설치/업데이트` · `백업 복원` · `루아 브리지 설치/갱신` |
| **세이브 데이터** | `세이브 내보내기` · `세이브 가져오기` · `미러에서 복원` · ☑ `가져올 때 동봉된 스키마도 함께 복원` |

## AI 내보내기/가져오기 — `TAB_SLICES` ★

각 탭 맨 위의 `tabAiTools(tabKey)`가 규격 내보내기 + `📥 가져오기`를 붙인다.

| 탭 | 갈아끼우는 키 | 특수 |
|---|---|---|
| `vars` | `vars`, `derived` | |
| `commands` | `vars` | `merge: 'cmd'` — **cmd 배정만 얹는다** (통째로 바꾸면 변수가 날아가므로) |
| `actions` | `actions` | |
| `checks` | `checks` | |
| `rules` | `rules`, `directives` | |
| `presets` | `setup` | `sub: 'presets'` — setup.ai 지침은 안 건드림 |

**`ai` · `status` · `setup(ai)` 탭에는 내보내기가 없다.** 즉 `updater.allow`·`mentions`·
`contextTurns`·`guide`는 AI에게 못 맡긴다 → **편집기 칸이 유일한 입력 경로.**

### 가져오기는 통째로 갈아끼운다
AI가 "고친 것만" 돌려주면 나머지가 사라진다. 플러그인이 방어한다:
- 항목이 이전의 60% 미만으로 줄고 원래 4개 이상이었으면 **⚠ 경고**
- `↩ 가져오기 되돌리기` 버튼이 그 탭에 뜬다
- 안내 문구: "손대지 않은 항목까지 전부 포함해 한 세트로 다시 달라"

`vars` 가져오기 후에는 다른 탭이 쓰던 변수가 사라졌는지도 검사한다.

## 탭별 주요 필드

### 변수
`[변수 추가]` · 타입 선택(`정수`/`실수`/`텍스트`/`ON/OFF`/`선택지`/`목록 (아이템)`)
· h4 `파생 변수 (자동 계산 — AI도 규칙도 직접 못 바꿈)`

### 명령
- 안내: "변수에 이름을 붙이면 그 이름의 명령이 생긴다 — 안 붙이면 그 변수엔 명령이 없다"
- 하나도 없으면 경고: "틀리면 매일 복리로 어긋나는 것(지속 수입·계약·봉급)부터 하나 열어 두시길"
- 붙일 변수 고르는 select는 **목록형을 맨 위로** 올린다
- h4 `유저가 이 목록을 보는 자리` — `{commands}`가 없으면 경고

### 상태창
- `표시 방식` (자동 구성 / 커스텀 HTML 템플릿) · `테마` · ☑ `접을 수 있게`
- `그룹 배치` (쌓기 / 탭 / 접기·펼치기 / 버튼 팝업) — **auto 모드에서만 표시**
- 템플릿 모드: `[탭 뼈대 넣기]` `[접기/펼치기 뼈대]` `[버튼 팝업 뼈대]` — 그 봇의 그룹·변수로 채워 나옴.
  이미 내용이 있으면 **한 번 더 눌러야** 덮어씀
- h4 `CSS 레시피` · `커스텀 CSS (자동으로 상태창 범위로 제한됨)` · `미리보기 (시작값 기준)`
- 조건부 템플릿: `id` · `표시 조건`

### 규칙·이벤트 (UI 순서 주의)
1. h4 `매 턴 자동 처리 (수입·소비 같은 정기 틱)`
2. h4 `상태 지시문 — 조건을 만족하는 동안 매 턴 AI에게 전달`  ← 이벤트보다 **위**
3. h4 `조건 이벤트 (조건을 만족하면 자동 발동)` — `조건` · ☑`1회만` · 효과 · `AI 통지`
4. h4 `랜덤 이벤트` — `턴당 발동 확률 %` · `가중치` · `쿨다운` · `조건` · 효과 · `AI 통지`

효과 행은 `[변수 선택] = [식]`. **`+=`가 아니라 `=`** — `gold + 10`이라고 써야 한다.

### 판정 (v0.40)
- 판정마다: id·표시 이름 / `굴림식`(rand 허용 유일 자리) · `보정식` · `목표치` / 등급 목록
- 등급마다: `조건`(비우면 기본 등급) · 등급 이름 · 효과(effectRows 재사용) · `연출 지시`
- `[+ 등급]` · `[🎲 액션 버튼 만들기]`(그 판정을 단 oneshot 액션 생성, 이미 있으면 `✓ 액션 버튼 있음`)
- `[판정 추가]`는 d20 4등급(대성공 roll==20 / 대실패 roll==1 / 성공 total>=vs / 실패) 뼈대로 시작

### 액션
안내: "실행 버튼은 화면 우상단에 뜬다 … 라벨을 이모지로 시작하면 알아보기 좋다 …
누르면 무장(ON)되고 다음 전송에 반영 — 1회성은 자동 OFF, 지속형은 끌 때까지 매 턴 적용"
필드: `영문id` · `버튼 이름` · 모드(`1회성`/`지속형`) · `쿨다운` · `사용 조건` · `판정`(v0.40 —
셀렉트, 켠 턴에 그 판정을 굴림. 판정이 없으면 "[판정] 탭에서 먼저 만들 것") · `AI 전달문` · 효과

### 새 시작
h4 `시작 프리셋 (플레이어가 고르는 난이도/배경 세트)` — `[시작값]` `[프리셋 추가]`
h4 `AI 최초설정 (세션 0 — 첫 대화로 시작 상황을 정함)` — ☑`사용` · 변수 체크박스 ·
`설정 대화 중 메인 AI에게 줄 지침` · `값 결정 가이드 (보조 AI용)`

### AI 설정
1. h4 `AI에게 매 턴 보낼 상태 요약 (자리표시자 {변수id})` + `[⚡ 변수로 자동 생성]`
2. ☑`이벤트 통지 포함` ☑`이벤트 우선 규칙 붙이기`
3. h4 `메인 AI 지침`
4. h4 `보조 AI에게 함께 보낼 최근 대화` — 1턴(기본) / 3턴(권장) / 5턴(토큰 많이 씀)
5. h4 `보조 AI가 조정할 수 있는 변수와 한도` — 행마다 `증가 한도`·`감소 한도`(또는 `최대 글자`)
   + ☑`등장할 때만` + `낱말` 칸(체크 시에만 나타남) + `액션 잠금` 칸(v0.39 — 액션 id 쉼표 구분,
   도움말이 현재 액션 id 목록을 보여 줌. 액션이 없으면 "[액션] 탭에서 먼저 만들 것" 경고)
6. `[허용 변수]` · `[⚡ 빠진 변수 모두 추가 (N개 — 숫자 한도는 직접 채우는 걸 권장)]`
7. h4 `보조 AI 추가 지시`

### 🔬 진단
`턴 수` · `시드 수` · `[🔬 진단 실행]` · `📊 직전 진단과 비교` · `🤖 이 결과로 AI에게 수정 요청하기`
· `액션별 기여도` · `프리셋별 실제 난이도`

잡아 주는 것: 영영 안 뜨는 이벤트 · 아무도 안 바꾸는 변수 · 한 번도 못 누르는 액션 ·
눌렀을 때 오히려 손해인 버튼 · 이름과 어긋난 난이도 순서.

### JSON
`① AI에게 스키마 만들게 하기` · `② 오류를 AI에게 돌려주기` · `③ 스키마 원본` + `편집기 반영`

## 편집기 주의

- `rerender()`가 DOM을 새로 만든다 → 확인용 임시 상태(두 번 누르기 등)는 **탭 함수 바깥**에 둘 것
- 전역 편집기가 캐릭터 전환 후에도 이전 내용을 유지해 **다른 봇 스키마를 덮어쓴 사고**가 있었다.
  v0.11에서 캐릭터 귀속 추적 + 설치/제거 전 자동 백업(`sim:schema-backup:<chaId>:<ts>`, 5개)을 넣었다
