# 🗺️ 지도 여러 장 — 문을 누르면 다음 지도가 펼쳐진다 (v1.26.0 예정)

> 상태: 구현 완료 (v1.26.0, 2026-11-15) · 집 실기 전 · 배포 전(유저 지시: 개발이 다 끝난 뒤 한 번에). 계획·판정 기록은 `docs/plans/2026-11-15-지도-여러장.md`.

## 0. 발단

- 커뮤니티에서 지도 기능으로 오라리오 전도를 만든 사람이 나왔다(2026-11-15, 유저 전달 스샷): 배경 그림 한 장 + 핀 39 + 이정표 4.
  도시 아래 던전(입구·상층부·중층부)까지 **한 장에 욱여넣었다** — 지도가 한 장뿐이라서.
- 유저: "구석 화살표를 누르면 다음 구역 지도가 나오게 해서 지도를 여러 개 만들 수 있나" → 지금은 안 된다(이정표는 글자뿐).
- 유저 판단(2026-11-15): **"지도니까 구경만 하고, 진짜 이동은 보조 모델이 움직이면서 맵 이동하면 그 맵에 맞춰 출력"**. 문을 장소 핀에도 다는 안에 동의("그렇게 하고").
- 같은 화면의 묵은 제보(2026-11-14 커뮤니티 ①): "지도라면 입력창을 통해 특정 지역을 추가하거나 변경" → §6 [＋ 장소]로 같이 다룬다.
  (같은 제보의 액션 입력창 `ask`·확인창은 엔진·무장·루아 브리지까지 닿아 **별도 문서**. 여기서 안 다룬다.)

## 1. 목표 · 비목표 · 반목표

**목표**
- 봇 하나에 지도를 여러 장. 장마다 배경 그림·비율·구역·장소·이정표.
- 이정표와 장소 핀에 "문"을 달면, 누를 때 그 장이 **펼쳐진다(구경)**.
- 위치 변수가 다른 장의 장소로 바뀌면, 패널이 **그 장을 띄우고** 거기에 "현재 위치"를 찍는다.
- 발자취·안개·찾아낸 곳·조건식은 지금 그대로 — 장이 늘어도 변수는 안 는다.
- 지도 한 장짜리 옛 스키마는 **한 글자도 안 고치고** 지금과 똑같이 그려진다.

**비목표**
- 눌러서 이동하기(이동 액션 무장) — 유저 판단으로 뺌. 이동은 보조 모델이 위치 변수를 바꾸는 지금 방식 하나.
- 확대·축소·끌기, 장끼리 이어 붙인 큰 지도, 장마다 다른 분류표.
- 상태창(채팅)에 지도 — 여전히 패널만.

**반목표 (돌아가도 실패인 것)**
- 구경이 상태를 건드린다 — 다른 장을 펼쳐 보는 것만으로 위치·발자취·스냅샷이 바뀌면 안 된다.
- 구경이 안개를 뚫는다 — 문으로 들어가 본 장에서 안 가 본 곳이 보이면 안 된다(안개 규칙은 장을 가리지 않고 같다).
- 옛 한 장짜리 지도의 모양·검증 결과가 달라진다.

## 2. 접근안

| | 모양 | 값 |
|---|---|---|
| **A (고름)** | `map` 안에 `sheets[]`를 더한다. 지금의 `map.zones/places/exits/bg/ratio`가 **첫 장** | 옛 스키마 무변경. 절 이름·탭·번들 조각·기능 지도·`activeSections`가 그대로. 첫 장만 모양이 다른(바깥에 풀려 있는) 비대칭이 남는다 |
| B | 최상위 `maps: [...]`로 새 절, `map`은 이관 | 대칭이지만 이관·검증·편집기 탭·번들 덮개·생성기(아틀리에)·규격서를 전부 고친다. 얻는 건 모양의 깔끔함뿐 |
| C | 프로필(🔀 판)마다 다른 `map` | 판은 채팅 단위라 한 채팅 안에서 장을 못 넘긴다. 용도가 다르다 |

A를 고른 이유: 지도를 쓰는 봇이 이미 배포돼 있고(아틀리에·커뮤니티 오라리오), "옛 것이 그대로"가 반목표다. 비대칭은 코어의 한 군데가 "첫 장 + sheets"를 같은 모양 목록으로 펴 주면 나머지 코드는 모른다.

## 3. 모양

```js
map: {
  label: '오라리오', icon: '🗺️',
  locVar: 'location', seenVar: 'visited', listVar: 'finds', fog: false,   // 장이 함께 쓴다
  categories: [...], css: '...',                                           // 장이 함께 쓴다
  // ── 첫 장 (지금 그대로) ──
  bg: '오라리오 전도', ratio: 1, note: '…',
  zones: [...],
  places: [
    { name: '바벨', x: 50, y: 48, cat: '중심 시설' },
    { name: '던전 입구', x: 50, y: 78, to: 'upper', desc: '…' },           // ← 문 달린 장소
  ],
  exits: [{ label: '남쪽 외부 지역', dir: 's' }, { label: '미궁', dir: 'se', to: 'upper' }],   // ← 문 달린 이정표
  // ── 더한 장 ──
  sheets: [
    { id: 'upper', label: '던전 상층', bg: '던전 상층도', ratio: 0.8, fog: true, note: '…',
      zones: [...], places: [{ name: '1층 대광장', x: 40, y: 30 }, …],
      exits: [{ label: '지상으로', dir: 'n', to: 'main' }, { label: '중층으로', dir: 's', to: 'middle' }] },
    { id: 'middle', label: '던전 중층', … },
  ],
}
```

- **장 id**: 영문·숫자·`_`·`-` (번들 조각이 장을 단위로 가르는 열쇠). 첫 장의 id는 예약어 **`main`**.
- **`to`**: 장소·이정표에 다는 문. 값 = 장 id(`main` 포함). 자기 장을 가리키면 오류.
- **장이 따로 갖는 것**: `label`(띠에 뜨는 이름 — 첫 장은 `map.label`) · `bg` · `ratio` · `note` · `fog`(없으면 `map.fog`를 따름 — "도시는 다 보이고 던전만 안개") · `bgAlways`(§4-5) · `zones` · `places` · `exits`.
- **장이 함께 쓰는 것**: `locVar` · `seenVar` · `listVar` · `categories` · `css` · `icon`.
- **이름은 지도 전체에서 하나**: 장소 name·alias, 구역 label·match가 **장을 넘어서도** 안 겹쳐야 한다(오류). 위치 변수 값이 어느 장의 어디인지가 이름 하나로 정해지기 때문 — 지금 규칙을 장 전체로 넓힌 것.
- 상한: 장 12 (첫 장 포함) · 장마다 장소 80·구역 40·이정표 16(지금 수치 그대로).

## 4. 동작

### 4-1. 어느 장을 띄우나
- 패널을 열면 **지금 여기가 있는 장**. 지금 여기 찾기는 **종류가 먼저, 장이 나중**: 전 장의 장소(name·alias) → 전 장의 찾아낸 곳 → 전 장의 구역(label·match).
  같은 종류 안에서는 첫 장부터 장 순서대로. (장마다 따로 돌면 앞 장의 찾아낸 곳이 뒷 장의 같은 이름 장소를 이겨, 그 장소에 발자취가 영영 안 적힌다 —
  찾아낸 곳 이름은 보조 모델이 적어서 검증이 못 막는다. 지금의 "장소가 찾아낸 곳을 이긴다"를 장을 넘어서도 지킨다.)
- 위치가 어느 장에도 없으면("지도 밖") 첫 장 + 지금처럼 "📍 값 (지도 밖)".
- 패널이 열린 채 턴이 돌아 위치가 다른 장으로 갔으면: **따라가는 중이면** 그 장으로 바뀌고, **구경 중이면** 보던 장에 머문다.

### 4-2. 구경
- 문 달린 **이정표**를 누르면 바로 그 장이 펼쳐진다. 문 달린 이정표는 눌리는 모양(밑줄·손가락 커서)으로, 문 없는 이정표는 지금처럼 글자.
- 문 달린 **장소 핀**을 누르면 지금처럼 아래 카드가 뜨고, 카드에 **[🗺 ○○ 지도 펼치기]** 단추가 붙는다(설명을 읽을 자리를 뺏지 않게 바로 넘기지 않는다).
  안 가 본 장소(known, 빈 마름모)의 문도 눌린다 — 들어가 본 장은 안개 규칙대로 가려져 있다.
- 구경 중(= 문이나 띠로 직접 장을 고른 뒤)엔 보는 장이 지금 여기의 장이 아니면 "현재 위치" 표시가 없고, 띠 옆에 **[📍 내 위치로]**가 뜬다. 누르면 따라가기로 돌아간다.
- 구경은 패널 화면 상태일 뿐이다 — 상태·스냅샷·채팅 변수에 아무것도 안 적는다. 패널을 닫았다 열면 따라가기부터.

### 4-3. 장 띠
- 장이 둘 이상이면 분류 단추 위에 장 이름 띠. 지금 여기의 장에는 📍. 띠의 이름을 눌러도 그 장을 구경한다.
- 띠에 뜨는 장: **첫 장 · 지금 여기의 장 · 발 디딘 장**(그 장의 장소·구역이 발자취에 있거나 찾아낸 곳 핀이 꽂힌 장) · **안개가 꺼진 장** · **지금 구경 중인 장**.
  안개 낀 장은 가 보기 전엔 띠에 없다 — 띠가 "던전 심층"이라는 이름으로 스포일러가 되지 않게. 문으로는 언제든 들어가 볼 수 있다.
- 장이 하나뿐이면 띠 없음(옛 지도와 같은 화면).

### 4-4. 발자취·안개·찾아낸 곳
- 발자취(`seenVar`): 정산이 지금처럼 "지금 여기의 이름"을 적는다. 찾는 범위만 전 장. **변수는 하나**.
- 안개: 장마다 `fog`(없으면 `map.fog`). 걷히는 규칙은 지금 그대로, 재료(발자취·known 식)는 전 장 공통.
- 찾아낸 곳(`listVar`) `"이름 (구역)"`: 구역 이름이 전 장에서 하나이므로, 그 구역이 있는 장에 꽂힌다. 구역을 못 찾은 것("자리를 못 찾은 곳")은 어느 장을 보든 아래에.
- 아래 숫자 줄("장소 39곳 · 이정표 4")은 보고 있는 장의 것.

### 4-5. 안 가 본 안개 장의 그림
지금 안개는 구역 사각형에 얹는 빗금과 핀 숨기기뿐이고, 배경 그림은 안개와 무관하게 늘 깔린다. 그대로 두면 문을 누르는 순간 던전 지도 그림이 통째로 보인다
(구역이 없는 그림 지도는 가려지는 면이 아예 없다) — "구경이 안개를 뚫는다"는 반목표에 걸린다.

- **더한 장(`sheets[]`)이 안개 낀 장이고 아직 발 디딘 적이 없으면 배경 그림을 깔지 않는다.** 빈 바탕 위에 "아직 가 보지 않은 곳이에요" 한 줄과, 소문으로 아는 곳(known)·이정표만.
  한 번이라도 발을 디디면(그 장의 장소·구역이 발자취에 있거나 지금 여기) 그림이 깔리고, 그 뒤는 지금 안개 규칙대로.
  **찾아낸 곳이 꽂힌 것은 발 디딘 것이 아니다**(띠에는 뜨지만 그림은 안 풀린다) — 구현 뒤 검토에서 나온 것: 그걸 치면 [＋ 장소 적기] 한 번으로 그림이 열린다.
  가려진 동안엔 안개 구역 사각형·채운 정도·아래 설명도 안 그리고, 장소도 적어 넣을 수 없다.
- **끄는 옵션(유저 2026-11-15: "그냥 보여주고 싶은 사람을 위해 선택 옵션으로")**: 장에 `bgAlways: true`를 주면 가 보기 전에도 그림을 깐다(핀·구역 안개는 그대로).
  기본은 가림. 편집기 장 줄의 체크 한 칸 "가 보기 전에도 배경 그림 보이기" — 안개 낀 더한 장에서만 뜻이 있어, 그 밖의 장에서는 칸을 흐리게 둔다.
- **첫 장은 지금 그대로**(안개가 있어도 그림은 늘 깔린다) — 옛 한 장짜리 안개 지도의 화면을 바꾸지 않으려고.
- 편집기 미리보기의 "안개 걷은 모습"에서는 늘 그림이 보인다.

## 5. 검증 (validateMap에 더하는 것)

| | |
|---|---|
| 오류 | 장 id 없음·형식 어긋남·겹침·`main` · `to`가 없는 장을 가리킴 · `to`가 자기 장(둘 다 **장이 하나도 없는 옛 지도에서는 경고** — v1.25.1까지 무시되던 키라 설치를 막지 않는다) · 장을 넘어 이름 겹침(장소 name·alias, 구역 label·match) · 장 12 초과 |
| 경고 | 발자취 `maxItems` < **전 장** 장소+구역 수 · 안개 낀 장에서 위치 선택지에도 없고 known도 없는 장소(영영 안개 — 지금 경고를 장마다) · 어느 문도 안 가리키고 위치 선택지에도 그 장의 장소가 하나도 없는 장(아무도 못 본다) |

- 위치 변수(enum)의 선택지에는 전 장의 장소가 다 들어가야 보조 모델이 고를 수 있다 — 지금도 그렇다. 장이 늘면 목록이 길어지는 것은 받아들인다
  (내 판단: 상한 12장이 사실상의 제동. 실기에서 보조가 헷갈리면 "지금 장의 이웃만 보여 주기"를 다음 후보로).

## 6. [＋ 장소] — 플레이 중에 적어 넣기

제보: "입력창을 통해 특정 지역을 추가하거나 변경". 제작자의 `places`를 플레이 중에 고치게 하면 번들 업데이트 때 덮인다 → 플레이어가 적는 곳은 이미 있는 **찾아낸 곳 목록(`listVar`)** 에.

- **켜야 생긴다**: `map.addPlace: true` + `listVar`가 있을 때만(편집기 [지도] 탭 02에 체크 한 칸 "플레이어가 장소를 적어 넣을 수 있게"). 기본은 끔 —
  이미 배포된 지도의 화면이 플러그인 업데이트만으로 바뀌면 안 되고, 찾아낸 곳 목록이 보조 모델 전용인 봇이 있다
  (아틀리에 `areas` = 아는 채집지, 12칸, 메인 프롬프트에 실림 — 플레이어가 고치면 경제가 흔들린다). `listVar` 없이 켜면 경고.
- 켠 지도의 패널 아래에 **[＋ 장소 적기]**. 누르면 패널 안 작은 칸: 이름 + 구역 고르기(**보고 있는 장의 걷힌 구역**) → [적기].
  `"이름 (구역)"`으로 목록 끝에 붙는다 — 보조 모델이 적는 것과 같은 모양이라 그리는 쪽·조건식은 그대로.
- 찾아낸 곳 핀을 누르면 카드에 **[이름 고치기] · [지우기]**(지우기는 같은 단추 두 번, 60초 — 규칙 #6, 리수 확인창 안 씀).
  제작자의 장소(`places`)에는 이 단추가 없다.
- 적는 통로는 **현황 탭 손수정과 같은 규약**(지금 상태에 바로 반영 · 마지막 스냅샷에 저장). 새 통로를 만들지 않는다.
- 거절: 빈 이름 · 이름에 괄호·@·쉼표 · 이름에 괄호·@가 든 구역 · 이름이 지도의 장소·구역·이미 있는 찾아낸 곳과 겹침 · 목록이 꽉 참(`maxItems`) · 보고 있는 장에 걷힌 구역이 하나도 없음 — 각각 칸 아래에 이유를 적는다.
- 단추는 켠 지도에만 그려진다 — 안 켠 지도의 `renderMapHtml` 출력은 지금과 글자까지 같다(§10 ①).
- **내 판단**: 자리는 지금처럼 구역 안에 자동으로 앉는다(이름 해시). 그림 지도에서는 "여기"를 눌러 찍고 싶겠지만, 좌표를 목록 글자에 실으려면
  항목 표기(`이름 (구역) @기한`)에 새 꼬리표를 만들어야 하고 그 글자가 상태창·프롬프트·보조 계약표에 다 비친다. 이번엔 안 한다(§9 다음 후보).

## 7. 편집기 [지도] 탭

- 01 기본 아래에 **장 줄**: `[첫 장 ▾] [＋ 장] [장 지우기]` + 고른 장의 이름·id·배경·비율·안개(지도 설정 따름 / 켬 / 끔).
- 03 미리보기 · 05 구역 · 06 장소 · 07 이정표는 **고른 장**을 편집한다. 미리보기에도 장 띠가 뜨고, 문을 누르면 그 장으로 넘어가 본다(편집기는 안개 걷은 모습이 기본이라 전 장이 띠에).
- 06 장소 · 07 이정표의 줄마다 **"누르면 펼칠 지도"** 고르기(없음 / 장 이름들).
- 장 id를 바꾸면 그 id를 가리키던 `to`가 같이 바뀐다. 장을 지우면 그 장을 가리키던 `to`는 빠진다(지우기 전에 "문 N개가 같이 빠져요" 한 줄).
- [지도 만들기](위치 선택지로 격자에 깔기)는 첫 장에만, 지금 그대로.
- **미리보기에 배경 그림을 띄운다** (내 판단, 2026-11-15 코드를 읽다 추가): 지금 미리보기는 그림 없이 종이 바탕뿐이라("편집기 미리보기엔 안 보여요"),
  그림 지도는 좌표를 눈대중으로 맞춰야 한다 — 커뮤니티 오라리오 지도(핀 39)가 그렇게 찍은 것. 장마다 그림이 다른 여러 장 지도에서는 더 아프다.
  편집기는 리수를 모르니 어댑터가 "에셋 이름 → 그림 주소"를 읽어 주는 훅 하나를 넘긴다(패널이 쓰는 그 길). 훅이 없거나 못 읽으면 지금처럼 종이 바탕.
- AI 쪽: 탭 AI 창구 요청서·전체 규격서 절·기능 지도 표(`FEATURE_MAP`) 줄에 "장 여러 개·문" 한 줄씩. 켜진 기능 현황은 "장 N · 장소 N"(이름 목록은 안 싣는다 — 길다).

## 8. 번들 조각과의 관계 (v1.25)

- 지도 탭 조각은 `map` 통째라 `sheets`도 같이 실린다. 장 id가 있으므로 **`map.sheets`를 id 목록 경로에 더해** 장 하나가 병합 단위 하나가 되게 한다
  (제작자가 중층만 고친 다음 판을 내면, 받는 사람이 고친 상층은 남는다). 첫 장의 `places`·`zones`는 지금처럼 통째 단위.
- **배경 그림은 카드 에셋이라 조각에 안 실린다.** 조각 고르기 화면에서 지도를 고르면 "배경 그림 N장(이름: …)은 파일에 안 들어가요 — 받는 분이 같은 이름으로 에셋을 넣어야 보여요" 한 줄을 띄운다.
  받는 쪽 요약 화면에도 같은 줄(그 이름의 에셋이 받는 봇에 없을 때만).
