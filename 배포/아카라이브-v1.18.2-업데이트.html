✨ 새 기능 🧑‍🎨 봇 제작 — 설정집을 대화로 정리해 로어북·캐릭터 시트로 v1.16.0

지금까지 SimCore의 AI 어시스턴트는 상태창·변수·규칙을 만드는 도구였습니다. 로어북과 캐릭터 시트는 여전히 손작업이었고, AI를 쓰더라도 봇 채팅 안에서 OOC로 주고받는 길뿐이었죠. "아예 봇 제작에 쓸 수 없나"는 말이 여럿 있었습니다.

편집기 사이드바에 [봇 제작]이 생겼습니다. 왼쪽은 설정집, 오른쪽은 전용 대화입니다. "북쪽 변경 마을 생존 봇. 마을엔 감시탑이 있고, 경비대장 아린이 뭔가 숨기고 있어" — 이렇게 이야기하다가 "정리해줘"라고 하면 어시스턴트가 설정집에 항목(세계·인물·장소·세력·규칙·용어·줄거리·문체)으로 쌓고, 그걸 리수 로어북 JSON과 캐릭터 시트로 내보냅니다.

설정집은 대화 이력이 아니라 작업본입니다

대화에 설정을 쌓아 가면 몇 턴 안에 컨텍스트가 터집니다. 그래서 설정집은 스키마 작업본과 같은 방식입니다 — 객체로 들고, 매 턴 요약(24KB)만 실리고, 어시스턴트는 바뀐 항목만 보냅니다(같은 이름이면 덮어쓰기). 항목은 손으로도 고칠 수 있고, 어시스턴트가 고친 건 [↩ 되돌리기]로 열 단계까지 돌아갑니다.

OOC로 짜는 것과 뭐가 다른가 — 심코어식 분담

로어북 = 안 변하는 것입니다. 플레이가 바꾸는 값 — 호감·소지금·상태·진행도 — 은 로어북이 아니라 🧩 심코어로 갈 것 목록으로 나뉩니다(변수·이벤트·액션·판정·비밀·무대 뒤·시나리오·갈림길). 본문에 "처음엔…", "현재…"가 들어가면 그건 변수 자리고, 밝혀지기 전엔 몰라야 하는 것은 로어북에 적으면 새니까 비밀로 갑니다. 규약이 어시스턴트에게 그렇게 시킵니다 — 낱말(키워드)은 장면에 실제로 나올 말 2~6개, 상시는 늘 필요한 것에만, 모르는 설정은 지어내지 말고 묻되 한 턴에 셋 이내.
그 목록 밑의 [💬 어시스턴트에게 보내기]를 누르면 요청문이 되어 AI 어시스턴트 입력칸에 들어갑니다. 거기서 변수·이벤트가 되고요.

· 내보내기 — [📋 로어북 JSON 복사]·[⬇ lorebook.json]은 리수 로어북 [가져오기]가 받는 형식 그대로입니다(캐릭터·채팅·전역·모듈 로어북 공통). [📋 캐릭터 시트 복사]는 설명란·첫 메시지에 붙일 글
· 캐릭터엔 글자 하나 안 씁니다 — 1단계입니다. 설정집은 이 기기에만 남고(카드·번들·세이브에 안 실림), 대화는 편집기를 닫으면 사라집니다
· 모델 — 💬 어시스턴트와 같은 통로라 생성 모델을 고릅니다. 보조 모델로 하면 품질이 떨어집니다 — 메인급을 권합니다. 직결 호출이 없는 환경은 손편집·내보내기만 됩니다
· 설정집이 커지면 요약 상한에서 본문이 생략됩니다(머리줄은 전부). 항목을 지우거나 합치세요

[스샷: 봇 제작 층 — 왼쪽 설정집(📚 항목·📁 폴더·🪪 캐릭터 시트·🧩 심코어로 갈 것)과 오른쪽 대화]

쓰는 곳 — 편집기 왼쪽 사이드바 작업도구의 [봇 제작]. 화면 위 "ⓘ 이 화면은?"을 펴면 같은 설명이 있습니다.

다음 — 2단계는 허가 체크를 켠 봇에 한해 로어북을 항목 단위로 직접 넣는 것(같은 제목만 교체, 나머지 보존, 백업·되돌리기), 3단계는 설명·첫 메시지·정규식입니다. 쓰기 없이 먼저 내는 건 수요부터 보려는 것이고, 캐릭터를 건드리는 쪽은 사고 이력(정규식 통째 교체)이 있어 천천히 갑니다.

✨ 새 기능 📚 보낼 것 고르기 — 어시스턴트에게 어떤 로어북을 보낼지 직접 v1.16.1 · 1.16.3

어시스턴트에 "현재 캐릭터 정보 포함"을 켜면 설명과 로어북을 같이 보냈는데, 20KB에서 앞에서부터 잘랐습니다. 로어북 순서는 봇마다 제각각이라 뭐가 빠지는지 알 길이 없었죠. "일부만 잘라 보내는 것보단 사용자가 정해서 보내는 게 낫다"는 제안에서 바꿨습니다.

· 전송 정보 카드의 "현재 캐릭터 정보 포함" 아래 📚 보낼 것 고르기 — 설명·로어북 항목마다 체크와 KB, [모두 켜기]·[모두 끄기]. 폴더가 있으면 "폴더 › 이름"으로 보입니다
· 한 번 고르면 네 곳이 같이 씁니다 — ✨ 창작·💬 대화·🧑‍🎨 봇 제작·규격서 복사. 선택은 캐릭터별로 기억합니다
· 자르지 않습니다. 20KB를 넘으면 ⚠로 알리고, 64KB가 최후 상한입니다(거기선 잘리고 표시). 빈 항목과 ⚙simcore 항목은 목록에 안 뜹니다(전부터 안 보냈습니다)

✨ 새 기능 📁 로어북 폴더 · 🪪 시트 형식 · 📥 캐릭 설정집 적재 v1.17.0

봇 제작을 처음 돌려 본 날 바로 나온 요청 셋입니다 — "내 시트 양식을 그대로 쓰고 싶다", "이미 써 둔 설정집을 재료로 넣고 싶다", "리수 로어북에 폴더가 있는데 어디에 만들지 정하고 싶다".

📁 폴더 — 리수 로어북 폴더째 내보냅니다

설정집에서 폴더를 새로 만들거나, 리수에 이미 있는 폴더를 골라 가져옵니다. 항목마다 폴더를 배정하고, 어시스턴트도 폴더가 있으면 알맞은 폴더에 넣고 맞는 게 없으면 새 폴더를 제안합니다. 내보내는 JSON에 폴더가 같이 실리고 리수 [가져오기]가 그대로 받습니다. 리수에 있는 폴더로 보낸 항목은 같은 캐릭터로 가져올 때 그 폴더 안으로 들어갑니다.

가져오기는 덧붙임입니다. 같은 JSON을 두 번 넣으면 항목도 둘, 새 폴더도 둘입니다(같은 제목을 교체하지 않습니다 — 리수 쪽 동작). "리수에 있는 폴더"는 그 캐릭터 안에서만 뜻이 있어, 다른 캐릭터·전역·모듈 로어북으로 가져오면 폴더 밖(맨 위)에 놓입니다.

🪪 시트 형식 — 쓰시던 OOC 명령어를 그대로

🪪 캐릭터 시트 구역 맨 위에 시트 형식(OOC 명령어) 칸이 있습니다. 쓰시던 캐릭터 시트 양식이나 OOC 명령어를 붙여 넣으면 어시스턴트가 설명란(desc)을 쓸 때 그 형식의 항목·순서·어조를 그대로 따릅니다. 유저 취향이라 기기 공통입니다 — 모든 봇에서 같이 씁니다.

📥 캐릭 설정집 적재 — 써 둔 원문이 재료가 됩니다

그 아래 칸에 이미 있는 설정집·메모 원문을 봇별로 붙여 넣습니다. 동봉 체크를 켜면 정리와 시트의 재료가 됩니다 — 설정집에 없는 것은 항목으로, 겹치면 설정집 기준. 48KB 위는 앞부분만 실리고 ⚠로 알립니다. 시트 형식과 원문 둘 다 어시스턴트가 못 바꿉니다 — 재료지 결과가 아니니까요. [🪪 시트 써 달라기]를 누르면 요청문이 입력칸에 들어갑니다. 상태 숫자·현재 상황은 시트에서 뺍니다(상태창이 보여 주니까요).

✨ 새 기능 🎲 추첨 효과 — 후보 풀에서 N명을 중복 없이 목록 변수에 v1.18.0

"일상용 봇에 NPC 목록과 캐릭터 풀을 두고 — 거주지에 N명, 장소를 옮기면 그 자리에 몇 명, 등장 인물 4명 제한 — 변수로 하는데, 명단을 처음 만들 때 랜덤 이벤트 표에 같은 이름을 수백 번 넣게 된다." 목록 효과의 추가는 글자 그대로라 식도 추첨도 없었고, 중복 없이 N명은 아예 길이 없었습니다.

이제 [변수] 탭 맨 아래 🎲 후보 풀에 이름을 적어 두고, 규칙·이벤트·액션의 효과에 [+ 🎲 추첨]을 둡니다. 풀은 한 줄에 하나 — 이름 | 가중치 | 그룹(가중치·그룹은 생략 가능), 그룹 보정은 그룹 | 같이 뽑힐 배수 | 최대 인원. 효과 줄은 어디서(풀 또는 목록 변수) · 몇 개(숫자 또는 식) · 어디로(목록 변수) · 대표(첫 당첨을 text/enum 변수에) · 빼고(이 목록에 있는 이름은 제외) · 난수 · 덧붙임입니다.

어떻게 뽑나 — 강제 묶음이 아니라 확률 보정

하나 뽑을 때마다 남은 후보의 가중치를 다시 셉니다. 같은 그룹이 이미 뽑혀 있으면 × 배수, 그 그룹이 최대 인원에 닿으면 0. 총 가중치에 비례해 하나 뽑고 후보에서 뺍니다. 배수 1.5면 같은 그룹(경비대·같은 반)이 같이 올 확률이 오르고, 0.5면 흩어집니다. 가중치 0은 안 뽑히고, 뽑을 수 있는 게 다 떨어지면 N보다 적게 끝납니다.
이름은 풀에 있는 것만, 난수는 엔진이 — LLM은 한 글자도 안 낍니다. 첫 당첨(이미 무작위)을 대표 변수에 넣으면 촌장·반장·첫 대상이 됩니다.

난수 — 효과마다 고정 / 새로

"가챠에 쓸 거면 변하는 게 좋고, 명단이면 고정이 맞다." 그래서 효과마다 정합니다 — 고정은 리롤해도 같은 명단, 새로는 리롤마다 다른 명단, 비우면 [규칙·이벤트]의 리롤 안정 설정을 따릅니다. 주민 명단은 고정, 오늘 시장에서 마주칠 넷은 새로 — 이런 식으로요. 

"pools": [ { "id": "npc_pool", "label": "마을 주민 후보",
  "items": [ { "name": "아린", "weight": 2, "group": "경비대" }, "브란", { "name": "세실", "group": "상인" } ],
  "groups": { "경비대": { "affinity": 1.5, "max": 2 }, "상인": { "affinity": 0.5 } } } ]

이벤트 (새 채팅에서 한 번만):  when "count(residents) == 0", once
  효과 { "sample": "npc_pool", "into": "residents", "n": 8, "leader": "mayor", "stable": true }

액션 🏪 시장에 간다:
  효과 { "sample": "residents", "into": "present", "n": 4, "stable": false }

· 새 채팅에서 한 번만 = 이벤트에 once + 조건 count(목록) == 0. 리롤하면 그 턴을 다시 계산하니 "새로"면 명단이 바뀌고 "고정"이면 그대로입니다
· 장소를 옮기면 그 자리에 넷 = 액션 효과에 어디서 → 주민 목록, 어디로 → 지금 자리 목록. 목록 변수도 풀처럼 쓸 수 있습니다(가중치·그룹은 풀에서 이름으로 찾습니다)
· 죽은 사람·떠난 사람은 "빼고"에 그 목록을. 상한은 목록 변수의 최대 항목 수 — 넘는 만큼은 안 뽑습니다
· 보조 AI가 이 명단을 고쳐야 하면 AI 설정 허용에 두고, 아니면 잠그세요. 추첨은 엔진이 하는 일이라 허용과 무관하게 돕니다
· 풀은 [변수] 탭에서 줄로 적습니다. 💬 어시스턴트의 패치로는 아직 안 들어가고, JSON을 통째로 넣는 길로는 됩니다(규격서에 실려 있습니다)
