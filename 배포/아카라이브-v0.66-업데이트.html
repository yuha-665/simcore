SimCore는 봇에 숫자로 굴러가는 상태를 붙여 주는 플러그인입니다. 식량·호감도·재정 같은 걸 AI에게 세라고 시키는 대신 시스템이 직접 계산하고, 그 결과를 상태창과 프롬프트로 내보냅니다.

⚠ 먼저 시간이 폭주하던 버그를 고쳤습니다 v0.65

증상 — 하루를 넘기는 버튼을 누른 뒤 "밤까지 잤다"처럼 쓰면, 그 다음부터 매 동작마다 몇 백 분씩 시계가 밀립니다. 시간 체계를 켠 봇이라면 누구나 밟을 수 있었습니다.

원인 — 시간을 굴리는 건 보조 모델인데, 그 보조에게 지금 몇 시인지를 안 알려주고 있었습니다. "3일 후" 같은 건 글에 답이 적혀 있어 잘 읽었지만, "밤까지"·"저녁이 되었다"는 지금 시각에서 빼야 하는 값이라 기준이 필요했습니다. 게다가 보조는 자기가 방금 민 시계를 확인할 방법이 없어서, 매 턴 처음처럼 "저녁까지의 간격"을 통째로 다시 넣었습니다.

수정 — 보조 프롬프트 머리에 [지금] 3월 2일 (월) 16:50을 붙이고, "여기서 새로 흐른 만큼만 밀어라"를 규칙으로 못박고, 직전 호출 이후 이미 반영된 변화를 함께 넘깁니다. 같은 구멍을 세 방향에서 막았습니다.

이미 어긋난 채팅은 인풋창에 /날짜 2026-10-05 22:00 처럼 쳐서 바로 맞출 수 있습니다. 새 채팅을 팔 필요 없습니다.

⚠ 먼저 채팅 명령이 "안 먹는 것처럼" 보이던 것 v0.65.1

/날짜 만 치면 사용법이 떠야 하는데 그냥 그대로 AI에게 보내졌습니다. 오타로 쓴 날짜, 쿨다운 거부, "바뀐 것 없음", "고를 선택지가 없음" — 답이 필요한 경우가 전부 그랬습니다.

엔진은 처음부터 제대로 답을 만들고 있었고, 그걸 화면에 내보내는 쪽에서 "값이 안 바뀌었으면 버린다"고 판단하고 있었습니다. 명령을 처음 써 보는 사람은 "명령이 안 되는구나"로 읽을 수밖에 없었습니다. 이제 모든 답이 그대로 뜹니다.

이번 업데이트를 한 줄로

봇 만드는 화면이 통째로 새로 그려졌고, 거의 모든 칸을 AI에게 맡길 수 있게 됐습니다.

큰 덩어리는 넷 — 편집기 UI 전면 재편(v0.66), 모든 탭에 AI 직결 생성(v0.62), 🧩 기능 카드 7장(v0.63), 달력 패널(v0.61).

✨ 새 기능 봇 만드는 화면이 새로 그려졌습니다 v0.66

이건 제가 만든 게 아닙니다. 한 분이 편집기 UI를 통째로 다시 짜서 "이런 식으로 바꿔 봤는데 쓰실 거면 쓰세요"라며 넘겨 주셨습니다. 검토해서 그대로 받았습니다. 고맙습니다.

달라진 것:

· 안내 문구를 처음 쓰는 사람 기준으로 다시 썼습니다. "숫자·문장·선택지·목록에 따라 저장 방식이 달라져요. 먼저 기본 변수를 정한 뒤 규칙과 상태창에서 사용하면 됩니다." 같은 식으로요. 400개 가까이 손봤습니다.

· 변수·명령·상태창 편집이 카드로 바뀌었습니다. 접기·펼치기, 문제 있는 것만 펼치기, 형식에 필요한 칸만 보이기, 어디서 쓰이는 ID를 바꾸려 하면 경고.

· ⠿ 를 잡고 끌어서 순서를 바꿉니다. 변수 카드도, 상태창 그룹·항목도요. ▲▼ 버튼은 그대로 있습니다.

· 진단 결과에서 [부분 패치 만들기]가 앞줄로 나왔습니다. 탭을 통째로 갈아엎는 옛 방식은 접힌 뒤로 내렸습니다.

조용히 고쳐진 것 — 선택지·목록을 이제 한 줄에 하나씩 편집합니다. 예전엔 쉼표로 나눠서, 좋음, 아주 같은 항목이 두 개로 쪼개졌습니다.

✨ 새 기능 이제 거의 모든 칸을 말로 시킬 수 있습니다 v0.62

탭마다 [✨ 만들어 달라기]가 붙었습니다. 요구를 한 줄 쓰고 누르면 그 탭 몫만 만들어 옵니다. 복사해서 다른 AI에 붙여넣는 길도 그대로 있습니다 (직접 호출이 막힌 환경용). 

변수    "눈 덮인 산장에서 겨울나기 — 체온·장작·식량을 굴리고 싶다"
명령    "골드는 /돈, 소지품은 /가방으로 치게"
상태창  "체력·허기·기온은 게이지로 맨 위, 소지품은 접어서 아래"
규칙    "체온이 0 아래로 3턴 가면 동사, 눈보라는 가끔 터지게"

요청할 때 이 봇에 이미 있는 변수 목록이 같이 나갑니다. 그래서 AI가 없는 이름을 지어내지 못하고, 받은 결과는 검사를 통과해야만 들어갑니다.

넣기 전에 무엇이 사라지는지 보여줍니다 v0.62.1

탭 단위 반영은 통째 교체라, AI가 하나만 빠뜨리면 그게 곧 삭제입니다. 이제 적용 전에 "사라질 것"의 이름을 목록으로 보여주고 확인을 받습니다 — 액션 사냥, 그룹 감정 식으로요. 잃는 게 없으면 그냥 지나갑니다.

상태창도 맡길 수 있게 됐습니다 — 무엇을 보여줄지(그룹·항목)와 어떻게 보일지(색·배치)를 따로 시킵니다. 구조를 맡겨도 공들여 짠 CSS와 커스텀 템플릿은 안 건드립니다.

✨ 새 기능 🧩 기능 카드 — 흔한 것들은 눌러서 얹습니다 v0.63 
🎛 상태창 한 벌     🏪 상점       📜 퀘스트 보드   📈 레벨·성장
💗 호감도 인물      🌳 스킬트리   ⚔ 편성표        📅 달력·일정

찍어내는 게 아니라 그 봇에 맞는 요청서를 만들어 AI에게 넘깁니다. 상점이든 스킬트리든 그 봇의 변수 이름을 알아야 성립하니까요.

못 쓰는 카드는 잠기고 이유가 옆에 뜹니다. 상점은 돈(숫자)과 소지품(목록)이 있어야 하고, 퀘스트 보드는 시간 체계가 켜져 있어야 합니다.

여러 절이 걸린 기능은 한꺼번에 안 만들고 순서대로 갑니다. 스킬트리는 변수 → 포인트 수입 규칙 → 편성표 순인데, 수입 없는 스킬 탭은 눌러 봐야 아무 일도 안 일어나는 죽은 화면이라서요.

✨ 새 기능 📅 달력 — 날짜를 눌러 일정을 등록합니다 v0.61

편성표에 이어 게임 패널 2호입니다. 채팅 화면의 📅 버튼을 누르면 월 그리드가 뜹니다.

달력에 세 가지가 표시됩니다 — 📌 기념일(생일·정기 행사. 매년·매달·매주), 📝 일정(날짜를 눌러 등록·삭제), ⏳ 기한(계약 만료 같은 게 자동으로 뜹니다).

일정은 그냥 목록 변수라, 등록해 두면 지난 일정은 알아서 정리되고, AI가 서사 중에 "다음 주에 만나기로 했다"를 등록할 수도 있고, 규칙 조건에도 그대로 씁니다.

진행 중인 채팅의 날짜를 고칠 수 있습니다 v0.61.1 — 시계는 채팅 시작 때 박혀서 시간 탭을 고쳐도 소급되지 않았습니다. /날짜 2026-10-05 로 바로 옮깁니다 (시각을 안 적으면 지금 시각 유지).

시간 켜기가 3택이 됐습니다 v0.63.1 — 그냥 켜기만 하면 시계가 멈춘 채 박혀서, 같은 날짜가 영원히 뜹니다. 날짜가 아예 없는 것보다 나쁩니다. 🌙 버튼·보고 / 📝 보고만 / 📆 턴마다 하루 중 골라야 켜집니다.

ON/OFF 명령 도움말이 틀렸던 것 v0.66 — "끄려면 off"라고 안내했는데 off는 실제로 안 먹었습니다. 0 또는 false입니다.
