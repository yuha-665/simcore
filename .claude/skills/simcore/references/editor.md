## AI 내보내기/가져오기 — `TAB_SLICES` ★

각 탭 맨 위의 `tabAiTools(tabKey)`가 규격 내보내기 + `📥 가져오기`를 붙인다.

| 탭 | 갈아끼우는 키 | 특수 |
|---|---|---|
| `vars` | `vars`, `derived` | |
| `commands` | `vars` | `merge: 'cmd'` — **cmd 배정만 얹는다** (통째로 바꾸면 변수가 날아가므로) |
| `actions` | `actions` | |
| `checks` | `checks` | |
| `rules` | `rules`, `directives` | |
| `presets` | `setup` | `sub: 'presets'` — setup.ai 지침은 안 건드림 |

**`ai` · `status` · `setup(ai)` 탭에는 내보내기가 없다.** 즉 `updater.allow`·`mentions`·
`contextTurns`·`guide`는 AI에게 못 맡긴다 → **편집기 칸이 유일한 입력 경로.**

### 가져오기는 통째로 갈아끼운다
AI가 "고친 것만" 돌려주면 나머지가 사라진다. 플러그인이 방어한다:
- 항목이 이전의 60% 미만으로 줄고 원래 4개 이상이었으면 **⚠ 경고**
- `↩ 가져오기 되돌리기` 버튼이 그 탭에 뜬다
- 안내 문구: "손대지 않은 항목까지 전부 포함해 한 세트로 다시 달라"

`vars` 가져오기 후에는 다른 탭이 쓰던 변수가 사라졌는지도 검사한다.

## 탭별 주요 필드

### 변수
`[변수 추가]` · 타입 선택(`정수`/`실수`/`텍스트`/`ON/OFF`/`선택지`/`목록 (아이템)`)
· h4 `파생 변수 (자동 계산 — AI도 규칙도 직접 못 바꿈)`

#### 변수 정리 마법사 (v0.45) ★
쓰이는 변수의 `✕`는 바로 안 지우고 **정리 계획**을 먼저 띄운다 (`planVarPurge`).
참조를 전 구간에서 걷어낸다 — 파생 **재귀 캐스케이드**, `updater.allow`, `setup.ai.vars`·`presets`,
`rules.onTurn`, `events`/`randomEvents`(**조건(when)이면 항목 통째, 효과면 그 한 줄만**), `choices`,
`directives`, `actions`, `checks`(굴림식이 무너지면 통째 + 그걸 가리키던 `check` 연결 해제),
`statusUI` 항목·빈 그룹·템플릿, `promptState`.

- 자리표시자: 산문(`promptState`·지시문 text)은 **값이 안 남는 줄째** 버리고,
  상태창 HTML은 **토큰만** 걷는다 (줄을 버리면 여는 태그만 남아 깨진다)
- 적용은 **원자적** — 정리 후 `validateSchema` 실패면 거부하고 이유 표시 · 되돌리기 1슬롯
- 아무 데도 안 쓰이면 계획 없이 그냥 지운다
- **이게 없으면 변수 삭제가 원천 불가능하다**: 참조가 `onTurn`·`promptState`·`setup`에도 있는데
  그 셋은 왕복 패치 미지원 영역이라, 패치로는 지울 수 없고 검증이 계속 거부한다 (실전 사고)

### 명령
- 안내: "변수에 이름을 붙이면 그 이름의 명령이 생긴다 — 안 붙이면 그 변수엔 명령이 없다"
- 하나도 없으면 경고: "틀리면 매일 복리로 어긋나는 것(지속 수입·계약·봉급)부터 하나 열어 두시길"
- 붙일 변수 고르는 select는 **목록형을 맨 위로** 올린다
- h4 `유저가 이 목록을 보는 자리` — `{commands}`가 없으면 경고

### 규칙·이벤트 (UI 순서 주의)

### 규칙·이벤트의 갈림길 칸 (v0.41)

### 판정 (v0.40)
- 판정마다: id·표시 이름 / `굴림식`(rand 허용 유일 자리) · `보정식` · `목표치` / 등급 목록
- 등급마다: `조건`(비우면 기본 등급) · 등급 이름 · 효과(effectRows 재사용) · `연출 지시`
- `[+ 등급]` · `[🎲 액션 버튼 만들기]`(그 판정을 단 oneshot 액션 생성, 이미 있으면 `✓ 액션 버튼 있음`)
- `[판정 추가]`는 d20 4등급(대성공 roll==20 / 대실패 roll==1 / 성공 total>=vs / 실패) 뼈대로 시작

**수정 요청은 패치 경로가 기본이다 (v0.45).** `📤 수정 패치 요청 복사 — 권장`이 지적 전체 +
항목 전문을 담아 나가고, 받은 패치는 JSON 탭 ②에 붙여넣는다. 탭별 통 교체 버튼은 남아 있지만

요청문에 "진단은 보조 AI를 안 돌린 결과라 **AI가 바꾸는 변수는 '안 움직임'으로 잘못 나온다**"를 명시한다.
🔵(low)는 어느 경로로도 안 보낸다.

잡아 주는 것: 영영 안 뜨는 이벤트 · 아무도 안 바꾸는 변수 · 한 번도 못 누르는 액션 ·
눌렀을 때 오히려 손해인 버튼 · 이름과 어긋난 난이도 순서.

**시뮬은 보조 AI를 안 돌린다** — 그 사각지대에 걸리는 것들은 v0.52부터 결함이 아니라
🔵로 분류돼 수정 요청에서 빠진다. 지적문에서 이 태그를 보면 **고치지 말 것**:

| 태그 | 뜻 |
|---|---|
| `AI 담당 문턱` | 문턱에 걸린 값을 보조 AI가 그 방향으로 민다 — 시뮬에선 시작값 근처에 머문다. **문턱을 내리면 실제 플레이에서 폭주한다.** 방향(`maxGain: 0`)·범위(선언 상한)·사거리(`maxDelta × 턴`)를 봐서 진짜 도달 불가와 구분한다 |
| `설정 의존` (🔵) | 조건의 bool/enum을 프리셋·액션·보조 AI가 세운다 — 다른 판에서는 뜬다 |
| `연쇄` | 안 뜬 이벤트**만이** 세우는 값에 막혔다 — 원인은 그 이벤트 하나다 (래치 짝의 회복 쪽·경보 플래그) |
| `안전장치` | `notify` 없는 값 되돌리기 규칙 — 안 뜨는 게 성공이다 |
| `후반부 이벤트`·`후반부 액션` | 판을 두 배로 늘리면 실제로 뜬다 — 턴 수를 올려 보라는 안내 |
| `측정 불가` | 보조 AI·최초설정·프리셋만 정하거나 효과 안에서만 쓰이는 값 (`pay_tmp`류) |

#### ② AI 왕복 패치 (v0.44, core/patch.js)
통짜 재생성 없이 **바꿀 부분만** 패치 JSON으로 받는 별도 입구. 흐름:
`📋 수정 요청 규격 복사` → 공홈 AI → 응답 붙여넣기 → `🔍 패치 검사` → 계획/충돌 확인 → `✅ 패치 적용`.

- 패치 형식: `{ patchVersion, add, update, remove }` — 섹션 키는 평평 (`vars`/`derived`/`checks`/
  `events`/`randomEvents`/`directives`/`actions`/`allow`)
- **add가 기존 id와 겹치면 정지** → 항목별 3지선다 (교체 / 새 id로 추가=패치 내 참조 일괄 개명 / 건너뛰기·기본)
- **같은 id를 remove+add에 같이 넣으면 거부** — 갈아엎기도 update(전문 다시 쓰기)로 (v0.44.1에서 프롬프트에 명시)
- update는 항목 **통 교체** — 다이제스트에 이벤트·액션·판정·지시문·allow **전문**이 실리므로 (v0.44.1)
  AI가 기존 본문을 보고 고쳐 쓴다. 변수는 계약표(요약)만
- remove는 diff에서 **기본 해제** (체크한 것만 삭제) · 적용은 원자적 (병합 후 validateSchema 실패 = 전무)
- **일괄 처리 (v0.44.2)**: 충돌 3건부터 [전부 교체]/[전부 새 id]/[전부 건너뛰기] + "충돌 다발 =
  낡은 규격 신호, 재내보내기가 안전" 힌트 · 삭제 후보 3건부터 [전체 체크]/[전체 해제]
- 적용 전 백업 1슬롯 `↩ 되돌리기` · statusUI·onTurn·setup·meta는 패치 미지원 → 기존 탭별 통 교체 경로
- 연속 패치 시 **적용 후 다시 내보내기** (옛 다이제스트 기준의 update는 낡음)

## 편집기 주의

- 라이브 검증 리포트(패널 하단)·패치 적용 보고의 **경고는 4건부터 `<details>`로 접힌다** (v0.44.1,
  `sce-fold`). 오류는 항상 펼침. 배경: 맨션봇 실전에서 mentions 겹침 경고 147줄이 오류를 가림
- `rerender()`가 DOM을 새로 만든다 → 확인용 임시 상태(두 번 누르기 등)는 **탭 함수 바깥**에 둘 것
- 전역 편집기가 캐릭터 전환 후에도 이전 내용을 유지해 **다른 봇 스키마를 덮어쓴 사고**가 있었다.
  v0.11에서 캐릭터 귀속 추적 + 설치/제거 전 자동 백업(`sim:schema-backup:<chaId>:<ts>`, 5개)을 넣었다
