# 설계 — 편성표 (게임 패널 1호, v0.55)

> 2026-08-01. 레코드 층 순서 2의 구현 — **"파티 편성표는 레코드 없이 지금 재료로 된다"**
> (design-레코드.md). 에셋 완주 직후, 유저의 다음 목표(편성표 → 장비창 → 상점 → 스킬트리)의 첫 판.

## 결정 — 사이드바 재편 (유저 결정)

> "이런 게임용 UI 출력부분은 액션버튼이 차지하는 사이드바로 할당하자. 액션버튼은
> 상태창 아래 뜨는 걸로 충분할 것 같아 — 이제 굳이 양쪽에 있을 필요 없을 듯."

- 우상단 `registerButton(location:'action')` 자리에서 **액션별 플로팅 버튼 제거** (v0.11~v0.54).
  v0.42 클릭 조작(상태창 범례가 진짜 버튼)이 생긴 뒤로 같은 버튼이 두 군데 있었다.
- 그 자리는 **게임 패널을 여는 유틸 버튼** 몫 — 지금은 편성표 하나, 장비창·상점도 이 통로로.
- 액션 토글 통로 셋:
  1. **상태창 범례 클릭** (v0.42, mainDom 권한) — 주 통로
  2. **편집기 패널**의 액션 토글
  3. **`/액션 이름`** 채팅 명령 (v0.55 신설) — mainDom 거부 환경의 폴백.
     /선택과 같은 내장 명령이고, `toggleAction`과 같은 검증(쿨다운·when)을 탄다.
     변수 cmd가 '액션' 이름을 선점하면 내장은 양보한다 (하위 호환).

## 게임 패널 (#sc-game)

- `showContainer('fullscreen')` 하나뿐인 컨테이너를 편집기(#sc-root)와 나눠 쓴다 —
  겉모습은 **팝업**(배경막 + 가운데 카드). 열 때 상대 루트를 `display:none`으로 비켜 준다.
- **우리 iframe DOM이라 클릭이 온전하다.** 좌표 히트테스트의 격자 취약성
  (리렌더마다 좌표가 흔들림 — design-레코드.md의 경고)이 여기엔 아예 없다.
  그 경고는 메인 채팅 DOM 얘기였고, 패널은 처음부터 그 문제 밖이다.
- 패널이 떠 있는 동안 `panelVisible = true` — 히트테스트 휴식·권한창 가림 방지 규약을
  편집기와 공유한다.
- **제작자 CSS**: `schema.party.css`를 `scopeCss(css, '#sc-game')`로 가둬 주입 —
  상태창 customCSS와 같은 기계, 같은 안전 규약 (앱 UI를 못 깨뜨림).
  클래스: `.scg-card .scg-title .scg-slot .scg-slot-label .scg-slot-val .scg-chip
  .scg-chip.scg-on .scg-chip.scg-used .scg-chip.scg-locked .scg-roster` +
  슬롯·칩에 `data-slot` / `data-val` 속성 (인물별 색).

## 편성표 데이터 모델 (schema.party)

```json
{
  "party": {
    "label": "편성", "icon": "⚔️",
    "slots": [ { "var": "front", "label": "전위" }, { "var": "rear" } ],
    "roster": "allies",
    "empty": "없음",
    "note": "동료를 영입하면 편성할 수 있다."
  }
}
```

- **슬롯 = enum 변수 하나.** 그 enum의 값 목록이 편성 후보다 — 제작자가 확정하고
  **AI는 명사를 못 만든다** (레코드 층 원칙 그대로). 슬롯마다 enum이 따로라
  "전위엔 전사만" 같은 슬롯별 제약이 값 목록으로 자연스럽게 표현된다.
- **보유 = list 변수 (roster).** 지정하면 목록에 있는 이름만 후보로 열린다 —
  영입/이탈은 보조 AI·명령이 목록을 움직인다 ("존재한다"와 "가지고 있다"의 분리).
  목록 규약 꼬리(`아린 @3일`, `바크 +2`)는 걷어내고 이름만 대조한다.
- **empty = 빈 슬롯 값.** 각 슬롯 enum에 있어야 한다 (없으면 비울 수 없음 — 검증이 잡는다).
- **중복 편성** (unique, 기본 켜짐): 이미 딴 슬롯에 앉은 인물을 고르면 게임 표준대로
  **이동**(원래 자리를 empty로), empty가 없으면 **맞교환**.
- **저장은 그냥 변수.** 상태창 `showWhen`·지시문 `when`·프롬프트 템플릿이 전부
  그대로 읽는다 — **새 표시 문법이 하나도 없다** (v0.31 기능이 그대로 화면 전환을 맡는다).
- AI도 편성을 움직이게 하려면 슬롯 변수를 `updater.allow`에 넣으면 된다 (선택 사항 —
  기본은 유저 전용, 편집기 탭이 현재 상태를 알려준다).

## 실기 확인 체크리스트 (다음 라이브 테스트)

- [ ] 스키마 설치 봇에서 우상단에 [⚔️ 편성] 버튼이 뜨는가 (전환만으로, 패널 안 열고)
- [ ] 버튼 → 팝업이 뜨고 슬롯 클릭 → 후보 칩 → 편성이 되는가
- [ ] 미보유 인물이 잠겨 보이는가 (roster), 중복 선택 시 이동하는가
- [ ] 편성 직후 조작줄·다음 턴 상태창에 반영되는가 (showWhen 분기)
- [ ] 액션별 플로팅 버튼이 사라졌는가 + 범례 클릭 토글이 그대로 되는가
- [ ] mainDom 거부 환경에서 `/액션 이름`으로 토글되는가
- [ ] 편집기 [편성표] 탭에서 만들기→설치가 도는가, 제작자 CSS가 팝업에만 먹는가
- [ ] 편집기(⚙️)와 편성표 팝업을 번갈아 열어도 화면이 안 겹치는가
