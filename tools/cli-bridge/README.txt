SimCore 다리 — 이 PC의 Claude Code · Codex로 봇 만들기 (실험 기능)

SimCore 편집기의 AI 어시스턴트(✨ 창작, 💬 대화, 🛠 봇 제작 등)를 리수의 API 모델 대신
이 PC에 설치된 Claude Code나 Codex로 돌립니다. API 키가 필요 없습니다.
RP 채팅과 상태 갱신은 그대로 리수 모델입니다.


왜 이 파일이 필요한가요
  플러그인은 리수 안에서 돌아서 PC 프로그램을 직접 실행할 수 없습니다.
  다리가 그 일을 대신합니다. 터미널에서 claude -p 나 codex exec 를 실행하는 것과 같은 방식입니다.


준비물
  - 리수 데스크톱, 또는 같은 PC에서 돌리는 셀프호스트(리스바드 포함)
    웹 리수는 실험적으로 됩니다. 고급 설정에서 [비권장 설정 보이기]를 켜면 나오는
    [직접 요청 보내기]를 켜야 닿습니다. 리수의 모든 요청이 브라우저에서 바로 나가게 되어
    모델에 따라 오류가 날 수 있으니, 다리를 쓸 때만 켜 두세요.
    포켓리스와 폰에서는 쓸 수 없습니다.
  - Claude Code 또는 Codex 로그인 (둘 중 하나면 됩니다)
    Claude Code는 터미널이나 VS Code 확장에서 로그인합니다. Codex는 터미널에서 codex login 을 실행합니다.
  - Node.js (https://nodejs.org 의 LTS)


쓰는 법
  1. 압축을 풀고 폴더 안의 cli-bridge.bat을 더블클릭합니다.
     압축 파일 안에서 바로 실행하면 안 됩니다. 같은 폴더의 simcore-cli-bridge.js가 필요합니다.
     윈도우가 경고하면 [추가 정보]를 누른 뒤 [실행]을 누르세요.
  2. 검은 창에 LISTENING http://127.0.0.1:5181 이 뜨면 켜진 것입니다. 창은 열어 둡니다.
  3. 리수 편집기의 생성 모델에서 [이 PC의 Claude Code · Codex (구독)]을 고릅니다.
     주소는 그대로 두고 [🔌 연결 확인]을 누른 뒤 모델을 고릅니다.
  4. 다 쓰면 창을 닫습니다. 봇을 만들 때만 켜 두면 됩니다.


다리가 하지 않는 것
  - 요청과 응답 내용을 어디에도 남기지 않습니다. 창에는 시각, 소요 시간, 토큰 수만 나옵니다.
  - 로그인 정보를 읽지도 저장하지도 않습니다. Claude Code와 Codex가 하던 로그인을 그대로 씁니다.
  - Claude Code는 도구 없이, 내 설정·CLAUDE.md·MCP·훅을 읽지 않고 실행합니다. 세션 기록도 남기지 않습니다.
  - Codex는 빈 임시 폴더에서 파일·명령 도구를 끄고, 내 Codex 설정을 읽지 않고 실행합니다.
  - 웹사이트가 다리를 부르지 못하게 막습니다. 리수 데스크톱, 같은 PC의 셀프호스트, risuai.xyz만 부를 수 있습니다.


알아 둘 점
  - 내 구독 사용량을 씁니다. 한도가 차면 기다리거나 생성 모델을 보조 모델로 돌리세요.
  - 이 PC(127.0.0.1)에서 본인만 쓰는 용도입니다. 다른 사람이 쓰도록 열지 마세요.
  - 실험 기능입니다. Claude Code나 Codex가 업데이트되면서 갑자기 안 될 수 있습니다.


안 될 때
  - 창이 바로 닫힌다
    이전에 받은 cli-bridge.bat이면 이 폴더의 파일로 바꾸세요.
    그래도 닫히면 이 폴더에서 명령 프롬프트를 열고 node simcore-cli-bridge.js 를 실행해 오류를 확인하세요.
  - Node.js not found
    Node.js LTS를 설치하고 다시 실행하세요.
  - 다리에 닿지 못했어요
    검은 창이 켜져 있는지, 주소가 http://127.0.0.1:5181 인지 확인하세요.
  - 로그인되어 있지 않아요
    터미널에서 claude 를 한 번 실행해 로그인하거나 VS Code 확장에서 로그인하세요.
  - 구독 사용 한도
    한도가 찬 것입니다. 기다리거나 생성 모델을 보조 모델로 돌리세요.
  - 포트를 못 열었어요
    다리가 이미 켜져 있습니다. 그 창을 쓰면 됩니다.
  - 이 주소에서 온 요청은 받지 않아요
    risuai.xyz가 아닌 주소의 웹 리수입니다. 그 주소를 SIMCORE_CLI_ORIGINS 환경변수에 넣고 다리를 다시 켜세요.
  - Codex가 오래돼서 설정을 끄는 옵션을 몰라요
    Codex를 업데이트하세요.
