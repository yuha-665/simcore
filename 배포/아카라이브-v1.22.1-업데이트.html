SimCore는 봇에 숫자로 굴러가는 상태를 붙여 주는 플러그인입니다. 식량·호감도·소지금 같은 걸 AI에게 세라고 시키는 대신 시스템이 직접 계산하고, 그 결과를 상태창과 프롬프트로 내보냅니다. 이번 글은 채팅 속 상태창 모양과 업데이트 방법 이야기입니다.

⚠ 먼저 — 채팅에서 상태창이 찌그러지던 것

해당하는 분 — 상태창을 🎨 [배치까지]로 만들었거나 HTML 템플릿을 직접 쓴 봇입니다. 기본 상태창(그룹으로 나열하는 모양)은 해당이 없습니다.
증상 — 편집기 미리보기는 깔끔한데 채팅에서만 2열 그리드가 찌그러지거나, 줄 사이가 벌어지거나, 탭을 눌러도 안 바뀌거나, 꾸민 스타일이 통째로 사라졌습니다.
원인 — 리수는 채팅에서 상태창을 두 번 더 읽습니다. 미리보기는 이 둘을 거치지 않아서 멀쩡해 보였습니다.
  ① 마크다운으로 한 번 더 — 빈 줄이나 깊은 들여쓰기에서 HTML이 끊기고, 그 뒤에 줄바꿈과 문단이 끼어듭니다
  ② CSS를 엄격하게 — 한 군데만 못 읽어도 그 스타일 묶음을 통째로 버립니다. CSS 안의 {uid}나 중첩 CSS가 그랬습니다
이제 — 플러그인이 상태창을 HTML 한 덩어리로 내보내고, CSS의 {uid}를 메시지 번호로 바꿉니다. 기본 스타일과 직접 쓴 스타일도 따로 실어서, 직접 쓴 쪽에 오류가 있어도 기본 모양은 남습니다. 템플릿은 고칠 필요 없이 플러그인만 바꾸면 됩니다.

· 눈에 띄는 차이 — 블록 태그로 시작하는 템플릿은 제목 밑 빈 여백이 미리보기만큼 줄어듭니다
· 태그 안의 빈 줄로 단락을 나누던 템플릿은 이제 미리보기처럼 붙어 보입니다. 띄우려면 <br>이나 <p>를 직접 넣어 주세요
· 플러그인이 대신 못 고치는 것(CSS 안의 {변수}, 중첩 CSS, 메시지마다 겹치는 탭 id)은 편집기 검증이 경고로 알려 줍니다

발단은 커뮤니티 제보입니다. "결과창에서는 깔끔한데 채팅에서는 2열 그리드가 찌그러진다, 탭 체크박스가 가끔 안 먹는다." 리수가 채팅에서 상태창을 읽는 과정을 그대로 재현해서 찾았습니다.

이번 업데이트를 한 줄로

이번 한 번만 직접 받으시면, 다음부터는 플러그인 목록의 버튼 하나로 업데이트됩니다.

🎨 상태창 꾸미기가 봇을 보고 디자인 — 분위기를 비워 두면 봇 설정에서 소재를 고르고, 재질 프리셋 10종이 생겼습니다

🔌 다리 받는 곳 — 플러그인과 같은 곳(GitHub)으로 옮겼습니다

✨ 새 기능 🔔 플러그인 목록에서 바로 업데이트 v1.21.5 · v1.22.1

업데이트가 생각보다 잦아서, 받을 때마다 파일을 찾아 가져오기 하는 수고를 덜었습니다. 플러그인 파일을 GitHub 배포 저장소에 올리고, 플러그인이 그 주소를 리수에 알려 줍니다.

· 리수 설정 → 플러그인 화면을 열면 리수가 새 판이 있는지 확인합니다. 있으면 SimCore 줄에 초록색 업데이트 버튼이 뜹니다
· 버튼을 눌러야 바뀝니다. 몰래 바뀌는 일은 없습니다
· 버튼이 안 보이면 플러그인 화면을 닫았다가 다시 열어 주세요. 새 판이 올라온 직후 몇 분은 늦게 보일 수 있습니다
· 플러그인 목록의 링크 아이콘을 누르면 배포 저장소가 열립니다. 바뀐 내용 기록도 거기 있습니다
· 업데이트 버튼은 최근 리수에 들어간 기능입니다. 버튼이 아예 없는 리수에서는 지금처럼 파일을 받아 가져오기 하시면 됩니다

설정 두 칸이 업데이트 뒤에도 남습니다

리수는 업데이트할 때(직접 가져오기도 같습니다) 플러그인 설정 칸을 비웁니다. 그래서 module_assets를 on으로 쓰시던 분(이미지가 모듈에 있는 봇)은 업데이트할 때마다 이미지가 사라졌을 겁니다. 이제 칸이 비어 있으면 지난번에 적어 둔 값을 그대로 이어 씁니다.

· 기본값으로 돌리려면 칸에 기본값(auto · off)을 직접 적어 주세요
· aux_model_mode가 지금 어떤 값으로 도는지는 관리 패널의 보조 모델 연결 테스트 → 연결 상세에 나옵니다. 지난 값을 이어 쓰는 중이면 그렇다고 적혀 있습니다
· module_assets는 따로 표시하는 곳이 없습니다. 모듈에 든 이미지가 계속 나오면 이어 쓰고 있는 겁니다
· 이번 v1.22.1로 넘어올 때만은 이전 판에 기억 기능이 없어서 기본값으로 돌아갑니다. 바꿔 쓰시던 분은 한 번만 다시 적어 주세요

✨ 새 기능 🎨 상태창 꾸미기가 봇을 보고 디자인합니다 v1.22.0

꾸미기를 AI에게 맡기면 어느 봇이든 비슷하게 딱딱한 모양이 나왔습니다. 원인은 AI에게 보내던 요청서에 있었습니다.

· 봇 정보가 없었습니다 — AI는 분위기 한 줄과 상태창 구조만 받아서, 어느 봇에나 맞는 무난한 모양을 냈습니다
· 예시 문구가 요청처럼 들어갔습니다 — 분위기 칸을 비우면 예시로 적어 둔 "낡은 신문지 느낌, 붉은 도장"이 그대로 실려서, 그쪽으로 쏠렸습니다
· 디자인 지침이 짧았습니다 — [획일적인 AI 디자인 줄이기]가 실제로는 여섯 줄 요약뿐이었습니다

이제 AI가 받는 것

· 이 봇의 정보 — 봇 이름, 설명 앞부분, 로어북 항목 이름만 보냅니다. 📚 보낼 것 고르기에서 끈 것은 보내지 않습니다
· 디자인 지침 — 그 세계에 실제로 있을 물건(영지 장부, 함선 계기판, 학생 수첩…)에서 색과 글꼴을 고르기, 계획을 먼저 적기, AI가 흔히 쓰는 모양(전부 알약 배지, 파랑→보라 그라데이션, 반투명 유리) 피하기, 휴대폰에서도 읽히는 글자 대비. 디자인 스킬 Hallmark와 Anthropic의 frontend-design에서 상태창에 맞는 것만 추렸습니다
· AI는 CSS 맨 위에 계획 주석(소재·색·글꼴·눈에 띄게 할 한 곳)을 먼저 적습니다. 왜 그렇게 만들었는지 커스텀 CSS 칸에서 읽을 수 있고, 채팅에는 나가지 않습니다

재질 프리셋 10종

기록부 · 양피지 · 석간 신문 · 암실 · 단말기 · 설계도 · 텃밭 수첩 · 가마 · 스티커 · 한밤. Hallmark의 테마를 상태창용으로 옮겼고, 글자 대비와 리수 채팅 규칙을 재질마다 검사했습니다.

· 출발 재질로 고르면 AI가 그 재질에서 출발해 이 봇에 맞게 바꿉니다. [스킨만]이면 [그대로 입히기]로 AI 없이 바로 입힐 수도 있습니다
· 세부 편집기 상태창 탭의 상태창 꾸미기 (선택) → 재질 프리셋 버튼도 이 10종으로 바뀌었습니다. 예전 레시피 다섯(양피지 장부·한밤 유리·로얄 골드·벚꽃·픽셀 레트로)은 뺐고, 이미 입힌 봇은 그대로입니다
· 재질을 입히거나 생성한 뒤엔 [꾸미기 되돌리기]로 한 단계 되돌릴 수 있습니다
· 기본 상태창 모양은 그대로입니다. 꾸미기를 시킬 때만 달라집니다

🔧 손질 같이 바뀐 것 v1.21.2 ~ v1.22.1

· 💾 번들을 넣은 뒤 뜨던 배너 — [번들 가져와 교체] 뒤에 "캐릭터에 아직 반영하지 않은 변경이 있어요"와 [💾 지금 적용]이 매번 떴습니다. 적용은 이미 끝난 뒤였고 배너가 잘못 뜬 것이었습니다. 이제 안 뜹니다. 그동안 누르신 [지금 적용]은 빈 목록 하나를 더 쓴 것뿐이라 해가 없습니다
· 상태창 검증 경고 — 채팅에서 버려지는 CSS, 메시지마다 겹치는 탭 id, 채팅에서 문단으로 바뀌는 줄을 편집기 검증이 알려 줍니다
· 🎨 [배치 생성] 결과의 빈 줄 — AI가 넣은 빈 줄을 적용할 때 걷어 냅니다. 직접 쓴 템플릿은 건드리지 않습니다
· 심코어를 안 쓰는 봇 — 플러그인이 켜져 있으면 모든 요청에서 메시지 끝 공백을 다듬고 있었습니다. 이제 심코어 표시가 든 메시지만 손댑니다
· 🔌 웹 리수에서 다리를 켜는 메뉴 — 지난 공지에 "설정의 plain fetch"라고 적었는데, 리수 화면에 없는 이름이었습니다. 정확한 경로는 고급 설정 → [비권장 설정 보이기]를 켜면 나오는 [직접 요청 보내기]입니다. 끈 채로 연결하면 뜨던 "다리가 이상한 답을 했어요 (HTTP 403)"도 이제 이 경로를 알려 줍니다

· 리수 데스크톱이나 같은 PC의 셀프호스트(리스바드 포함)에서 됩니다. 웹 리수는 실험적이고, 포켓리스·폰에서는 쓸 수 없습니다
· 내 Claude Code·Codex 구독 사용량을 씁니다. 본인 PC에서 본인만 쓰는 용도입니다
