# 🔀 프로필 실기 — 깡통봇용 시험 번들

`프로필시험-번들.json`을 빈 캐릭터에 넣으면 판 네 벌(기본·마법사·생존·깨진 판)이 바로 선다.
번들은 `node 프로필시험/make-bundle.js`가 만든다 — 고칠 땐 그 파일만.

| 판 | 무엇을 시험하나 |
|---|---|
| 기본 | 체력 100 · 금화 30 · 장소 · 소지품, 🏕 휴식 |
| 마법사 | 바뀐 항목(체력 70) · 새 변수(마나 50) · 새 버튼(🔮 명상) · 새 지시문 · 시작 소지품(지팡이) |
| 생존 | 지운 변수(금화 없음) · 매 턴 정산(배고픔 +1) · 조건부 버튼(🍞 빵 먹기 — 빵이 있을 때만) |
| 깨진 판 | 일부러 못 얹게 만든 판 — 고르면 기본 판으로 돌고 알림이 떠야 정상 |

로어북 `판 안내`는 `{{getvar::sim_profile}}`로 마법사·생존 판에서만 한 줄을 싣는다(채팅 변수 미러 시험).
상태창 제목이 `프로필 시험 · <판>`이라 지금 어느 판인지 바로 보인다.

## 준비

1. `feat/profile` 브랜치의 `simcore.plugin.js`(v1.24.0)를 임포트 — 플러그인 목록 이름에 v1.24.0이 보이면 된다.
2. 리수에서 새 캐릭터를 하나 만든다. 이름만 있으면 된다(설명·인사말 없어도 됨).
3. 심코어 패널 → 💾 세이브 → 🧳 개조 번들 **[번들 가져와 교체]** → `프로필시험-번들.json` → 한 번 더 눌러 적용.

## 시험 순서 — 정상이면 이렇게 보인다

1. **기본 판** — 새 채팅에서 두 턴. 상태창 제목 `프로필 시험 · 기본`, 체력 100 · 금화 30, 🏕 휴식 버튼.
2. **판 고르기** — 새 채팅 → [현황 → 새 시작]의 🔀 단추에 기본·마법사·생존·깨진 판. 시작 전이라 한 번 누르면 바로 바뀐다.
   마법사 → 체력 70 · 마나 50 · 🔮 명상. 두 턴 진행. 리수 프롬프트 미리보기에 `[이번 판: 마법사]` 줄이 있으면 CBS 미러 정상.
3. **채팅마다 따로** — 1번 채팅으로 돌아가면 기본 판 그대로.
4. **진행 중 바꾸기** — 마법사 채팅에서 생존을 **두 번** 누른다 → 금화 칸이 없어지고 배고픔 0부터, 체력은 이어진다.
   지난 메시지 상태창은 마법사 모양 그대로. 한 턴 → 배고픔 1. 🍞 빵 먹기를 누르면 빵이 빠지고 버튼이 사라진다.
5. **리롤** — 판을 바꾼 직후 마지막 응답을 리롤 → 생존 판 그대로.
6. **새 채팅의 판** — 새 채팅을 열면 마지막으로 고른 판(4번의 생존)으로 시작한다.
7. **깨진 판** — 단추에 ⚠가 붙어 있다. 골라 보면 기본 판 모양으로 돌고 상태줄에 🔀 "못 얹었어요" 알림.
   다시 기본으로 고르면 알림이 걷힌다.
8. **번들 다시 교체** — [편집 작업공간 → 🔀 프로필]에서 `내 판`을 하나 만들고 번들을 다시 가져와 교체 → `내 판`이 남아 있어야 한다.
9. **폰** — 포켓리스에서 🔀 단추와 프로필 카드가 넘치지 않는지.

이 번들과 별개로, **프로필이 없는 평소 봇이 v1.24.0에서 그대로 도는지**가 제일 중요하다
(로드 순서·편집기 배너·번들 교체·브리지가 프로필 없는 봇도 지나간다).
