0. 이 가이드 하나면 됨


심코어 가이드 1~2탄이 옛날 방식(규격서 복사해서 공홈 왕복) 기준이라, 요즘 버전 쓰는 사람은 오히려 헷갈린다는 제보가 있었음. 그래서 v0.94 기준으로 봇 제작 흐름만 처음부터 끝까지 다시 씀. 이 가이드 하나로 봇 하나가 나오고, 1~10탄은 세부 기능이 궁금할 때 찾아보는 사전이라고 생각하면 됨.


시작 전에 제일 중요한 것부터. AI한테 시키는 길이 두 개인데, 하나만 쓰면 됨.


기본길 = ✨ AI에게 맡기기. 인풋창에 말로 시키면 리수 안에서 AI가 직접 만들어 줌. 복사·붙여넣기 없음.

옆길 = 규격서 복사. AI 호출이 차단된 환경이거나 API 없이 공홈만 쓸 때, 규격서를 복사해 밖에서 작업하고 결과를 가져오는 우회로.

기본길이 되면 옆길은 평생 쓸 일 없음. 둘을 섞어 쓰면 그때부터 꼬임.


(예전 가이드는 옆길이 본편이었음 — 그때는 기본길이 없었으니까. 지금은 반대임)



1. 준비 — 2분 걸림


① 플러그인 파일을 리수에 임포트함 (이미 했으면 통과)

② 봇을 열고 심코어 관리 패널에서 [현재 캐릭터에 설치/업데이트]를 누름 — 이걸 눌러야 그 봇에 심코어가 붙음


[스샷: 관리 패널 — 설치/업데이트 버튼]



2. 제일 쉬운 시작 — 템플릿 훔치기


백지에서 시작할 필요 없음. [새로 만들기]에 완성된 템플릿이 16종 있음 — RPG, 연애, 경영, 미궁 탐사, 아포칼립스, 아이돌 프로듀스, TRPG 판정...


[스샷: 새로 만들기 템플릿 목록]


만들려는 봇과 장르가 비슷한 걸 골라 설치하면 변수·규칙·상태창·액션이 전부 짜인 채로 들어옴. 그대로 놀아도 되고, 여기서부터 아래 3번(AI에게 맡기기)으로 내 봇에 맞게 개조하는 게 제일 빠른 길임.


완전 백지에서 시작하고 싶으면 바로 3번으로.



3. 본편 — ✨ AI에게 맡기기


봇 편집 사이드바에서 ✨ AI에게 맡기기로 들어가면 인풋창이 있음. 여기에 원하는 봇을 말로 적으면 됨. 공홈에서 대화하듯이.


"던전 탐사 봇. HP랑 소지금 있고, 층수 내려갈수록 위험해지고, 보스 잡으면 보상 나오게"


적고 [✨ 생성] 누르면 끝. 수십 초 뒤에 작업본이 나옴.


[스샷: 인풋창 + 생성 버튼]


나온 작업본은 바로 적용되지 않음. 뭐가 만들어졌는지 요약·경고를 보여주고, 사람이 [반영]을 눌러야 들어감. 마음에 안 들면 안 누르면 그만이라 몇 번을 다시 시켜도 봇이 안 망가짐.


[스샷: 작업본 계획/요약 화면]


그리고 여기서부터가 진짜임. 한 번에 완벽하게 만들려고 하지 말고, 반영한 뒤에 계속 대화로 고치면 됨.


"호감도 시스템 넣어줘" → 반영

"상태창에 날씨도 띄워줘" → 반영

"돈이 너무 잘 벌림. 수입 좀 줄여줘" → 반영


이미 만든 봇에 시키면 전체를 갈아엎는 게 아니라 시킨 부분만 고치는 패치로 들어와서 안전함. 잘못 반영했으면 [↩ 되돌리기]도 한 번 남아 있음.


특정 부분만 집중적으로 시키고 싶으면 세부 편집기의 각 탭(변수·규칙·액션·시나리오...)에도 ✨ 만들어 달라기 버튼이 따로 있음. 그 탭 몫만 만들어 옴.



4. 생성 모델 팁 — 잘리면 모델을 바꿔라


인풋창 옆에 생성 모델 선택이 있음 (보조/메인/직접 지정). 기본값은 보조 모델인데, 봇을 통째로 처음 만들 때는 [메인 모델] 추천임.


[스샷: 생성 모델 선택]


이유: 통짜 생성은 출력이 긴데, 보조 모델은 응답 최대 길이가 짧게 잡힌 경우가 많아서 JSON이 중간에 잘림. 잘리면 몇 번을 다시 돌려도 같은 자리에서 또 잘림 (길이 한계는 운이 아니라 설정이라서). v0.94.1부터는 잘리면 "응답이 중간에 잘렸어요"라고 원인을 정확히 알려주니, 그 안내가 뜨면:


① 생성 모델을 메인/직접 지정으로 바꾸거나

② 리수 설정에서 그 모델의 응답 최대 길이(max tokens)를 늘리거나

③ 통째로 말고 탭 단위로 쪼개서 시키면 됨


수정 대화(패치)는 출력이 짧아서 보조 모델로도 잘 됨.



5. 옆길 — 규격서 복사 (API 없는 사람 전용)


[✨ 생성]을 눌렀는데 "호출이 차단됐어요"가 뜨는 환경이거나, API 없이 공홈 구독만 쓰는 경우에만 이 절을 읽으면 됨. [✨ 생성]이 잘 되는 사람은 여기 볼 필요 없음.


인풋창 아래 [규격서 복사]를 누르면 요청 내용 + 봇 정보 + 작성 규칙이 통째로 복사됨. 이걸 공홈(웹 AI)에 붙여넣으면 AI가 JSON을 만들어 줌. 그 JSON을 복사해서:


· 봇 전체 작업본이면 → 🧾 JSON 관리자의 전체 작업본 칸에 붙여넣기

· 탭 하나 몫이면 → 그 탭의 [📥 가져오기] 칸에 붙여넣기


코드펜스(```)나 앞뒤 설명이 붙어 있어도 알아서 벗겨냄. 붙여넣은 게 형식에 어긋나면 검사가 막아 주니까 봇이 망가질 걱정은 없음.


[스샷: 규격서 복사 칸 — "옆길" 표지판 보이게]



6. 마무리 — 배포 전엔 🔬 진단


봇이 얼추 완성됐으면 🔬 진단을 한 번 돌리셈. 봇을 수백 턴 자동으로 굴려서 — 영영 안 터지는 이벤트, 영영 안 열리는 시나리오 막, 안 움직이는 변수 같은 걸 미리 잡아 줌.


[스샷: 진단 결과 화면]


잡힌 문제는 [패치 만들기] 누르면 AI가 고쳐 옴 — 이것도 계획 보여주고 사람이 반영을 누르는 방식이라 안전함. 배포하고 나서 "이 이벤트 안 나오는데요" 소리 듣기 전에 플러그인이 먼저 알려주는 거임.



정리


① 설치하고 봇에 [설치/업데이트] 한 번

② 비슷한 템플릿 깔고 시작 (백지보다 빠름)

③ ✨ 인풋창에 말로 시키고 [생성] → [반영] → 이후 대화로 계속 수정

④ 통짜 생성은 메인 모델로 — 잘리면 모델 탓이니 다시 돌리지 말 것

⑤ 규격서 복사는 [✨ 생성]이 안 되는 환경 전용 옆길

⑥ 배포 전 🔬 진단 한 번


막히는 데 있으면 댓글로. 세부 기능(판정·갈림길·에셋 팩·편성표...)은 가이드 3~10탄 참고.
