SimCore는 봇에 숫자로 굴러가는 상태를 붙여 주는 플러그인입니다. 식량·호감도·재정 같은 걸 AI에게 세라고 시키는 대신 시스템이 직접 계산하고, 그 결과를 상태창과 프롬프트로 내보냅니다.

이번 업데이트를 한 줄로

이제 복사-붙여넣기 왕복도 안 합니다 — 입력창에 말하면 플러그인이 직접 AI를 불러서 만들어 옵니다.

지난 판(v0.44)에서 "고치는 것도 AI에게"까지 왔는데, 그래도 규격서 복사해서 AI 사이트 다녀오는 왕복은 남아 있었죠. 리수를 쓰는 사람은 어차피 모델이 연결돼 있는데 왜 밖을 다녀와야 하나 싶어서 — 안으로 접었습니다. 화면도 그 김에 갈아엎었고요.

✨ 새 기능 AI에게 맡기기 — 말하면 끝 
봇 편집 맨 위 입력창에 원하는 걸 적고 [✨ 생성] — 그게 전부입니다
   "산적 습격 이벤트 추가해줘. 경계가 5 이상이면 발동하고 금화를 뺏기게"

스키마가 없는 봇이면 통째로 만들어 오고, 있으면 바꿀 부분만 패치로 옵니다
   계획: 추가 2 · 교체 0 · 삭제 후보 0 · 충돌 0   → [✅ 패치 적용]

키 입력도 없습니다. 리수에 이미 연결된 보조 모델을 그대로 씁니다. 봇 설명·로어북도 자동으로 같이 실려 가서, 세계관을 다시 설명 안 해도 됩니다.

망칠 방법이 없습니다. v0.44의 안전장치가 그대로 밑에 깔려 있습니다 — 적용 전에 계획을 보여주고, 겹치면 멈춰서 물어보고, 검증 못 넘으면 아무것도 안 바뀌고, 되돌리기 한 번이 항상 남습니다. AI가 쓰레기를 보내와도 스키마는 멀쩡합니다.

API 없이 공홈 구독(GPT·클로드 웹)을 쓰시는 분은 [📋 복사해서 다른 AI에게]가 그대로 있습니다. 내용물이 생성 버튼과 똑같은 규격서라 결과도 똑같습니다.

화면 개편 사이드바 + 3구역 — 스크롤 지옥 끝

탭 10개가 한 페이지에 늘어서 있던 편집기를 목적별 3구역으로 나눴습니다. 넓은 화면에선 왼쪽 사이드바로, 폰에서는 지금까지처럼 상단 탭으로 나옵니다. 

✨ AI에게 맡기기   ← 기본. 말로 시키고, 눈으로 확인하고, 굴려보는 곳
🧾 JSON 작업대     ← 복붙 왕복파의 홈그라운드 (통짜·패치·오류 돌려주기·원본)
🧰 심층 편집       ← 변수·이벤트·액션을 손으로 직접 만지는 곳

세 구역은 같은 스키마를 보는 다른 창문일 뿐이라, 어디서 고치든 나머지에 즉시 반영됩니다.

✨ 새 기능 만든 걸 바로 눈으로 — 창작 · 결과 · 진단

👁 결과 탭 — 지금 스키마가 그리는 상태창 미리보기가 항상 떠 있고, 그 아래 만들어진 것들 도감이 이벤트·액션·판정을 사람 말로 풀어줍니다. 발동 조건이 뭔지, 뭘 얻고 잃는지 — JSON 안 읽어도 됩니다.

🔬 진단 탭 — 스키마를 실제로 수십 턴 굴려서 영영 안 뜨는 이벤트, 한 번도 못 누르는 액션 같은 걸 찾아내는 건 전부터 있었는데, 이제 결과 옆에 [✨ 이 결과로 바로 고쳐달라기]가 붙었습니다. 찾은 문제를 그 자리에서 AI에게 던지고, 패치가 오면 확인하고 적용. 왕복 끝.

✨ 새 기능 상태창 꾸미기도 말로 
🎨 스킨만   "낡은 신문지 느낌, 세리프 폰트, 붉은 도장 포인트"  → 색·폰트만 갈아입음
🖼 배치까지  "왼쪽에 초상화 칸, 오른쪽 수치 2열, 하단에 계약 칩" → 상태창을 통째로 새로 그림

한 줄 적고 생성 누르면 바로 위 미리보기에 적용됩니다. 마음에 안 들면 [↩ 되돌리기] 한 번. 배치 쪽은 AI가 없는 변수를 갖다 쓰면 적용 자체가 거부되니 여기도 망가질 일은 없습니다.

그 외

· 생성 모델 선택 — 기본은 보조 모델. 보조에 번역용 싼 모델을 꽂아두신 분은 스키마 생성이 부실할 수 있으니, 그때만 잠깐 상위 모델로 바꾸거나 [직접 지정]을 쓰세요.

· 실패하면 이유가 보입니다 — 생성이 안 될 때 "왜 안 되는지"가 화면에 그대로 뜹니다. 조용히 삼키지 않습니다.

· 호환 — 기존 봇·세이브 전부 그대로 돕니다. v0.43 시절 세이브 파일로 직접 확인했습니다.
