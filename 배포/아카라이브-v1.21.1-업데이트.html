처음 보시는 분께

SimCore는 봇에 숫자로 굴러가는 상태를 붙여 주는 플러그인입니다. 식량·호감도·소지금 같은 걸 AI에게 세라고 시키는 대신 시스템이 직접 계산하고, 그 결과를 상태창과 프롬프트로 내보냅니다. 이번 글은 봇을 만들 때 쓰는 편집기 어시스턴트 이야기입니다. 채팅과 상태창은 바뀌지 않았습니다.

⚠ 먼저 — 🔌 다리 cli-bridge.bat이 켜지지 않던 것

해당하는 분 — 지난 공지의 🔌 이 PC의 Claude Code · Codex 다리를 받으신 분입니다.
증상 — cli-bridge.bat을 더블클릭하면 창이 바로 닫히고, 편집기의 [🔌 연결 확인]에 "다리에 닿지 못했어요"가 뜹니다.
원인 — 배포한 배치 파일의 줄바꿈 형식과 안에 든 한글이 겹쳐, 윈도우가 파일을 읽다가 중간에 멈췄습니다. 쓰시는 분의 설치나 환경 문제가 아니었습니다.
이제 — 고친 cli-bridge.bat을 받아 기존 파일에 덮어쓰세요. 플러그인을 다시 임포트해도 이 파일은 바뀌지 않습니다. simcore-cli-bridge.js는 그대로 두시면 됩니다.
확인 — 검은 창에 LISTENING http://127.0.0.1:5181이 뜨고 창이 그대로 있으면 켜진 겁니다. 그다음 [🔌 연결 확인]을 다시 누르세요.

[다리 파일 링크: cli-bridge.bat]

다리 폴더에서 명령 프롬프트를 열고 node simcore-cli-bridge.js를 실행해도 같습니다. 다리를 안 쓰시면 해당이 없습니다.

이번 업데이트를 한 줄로

편집기 어시스턴트가 심코어의 자체 기능을 알게 됐습니다. 상점·보드를 액션으로 흉내 내는 대신 먼저 권합니다.

🗺 기능 지도 — 상점·보드·메신저·의뢰판을 포함한 17개 기능과 이 봇의 실제 설정을 어시스턴트가 봅니다
📦 준비와 안내 — 바로 못 넣는 기능은 필요한 변수를 준비하고, 어느 탭에서 무엇을 채울지 알려 줍니다
🧩 상점 카드 · 봇 제작 — 🧩 [상점] 카드가 이제 시스템 상점을 만듭니다

발단은 커뮤니티 제보입니다. "자체 상점이나 보드 기능이 있는데도 어떻게든 액션 버튼에 상태창을 연동하려 한다. 물어보면 모르는 것처럼 말한다."

✨ 새 기능 🗺 어시스턴트가 자기 기능을 압니다 v1.21

모델 탓이 아니었습니다. 어시스턴트가 실제로 받는 프롬프트를 열어 봤더니 제보 그대로였습니다.

· 기능의 이름조차 없었습니다 — 작업본이 있는 봇의 프롬프트에 상점·보드·메신저·의뢰판이 한 번도 나오지 않았습니다. 모르는 기능을 권할 수는 없으니, 아는 도구인 액션과 상태창으로 만든 겁니다
· 켜진 기능도 보지 못했습니다 — 네 기능을 다 켠 봇에서도 설정값이 프롬프트에 없었습니다. "모른다"는 답이 사실이었습니다
· 🧩 [상점] 카드도 같았습니다 — 자체 상점이 나오기 전 방식 그대로 구매 액션 묶음을 만들고 있었습니다

이제 어시스턴트가 보는 것

💬 대화 · 🗂 정리해서 반영 · ✨ 창작이 모두 아래 셋을 받습니다.

· 기능 지도 — 상점·보드·메신저·의뢰판·편성표·달력·시나리오·비밀·무대 뒤·되감기 등 17개 기능이 무슨 일을 하고, 어느 탭에 있고, 무엇이 필요한지
· 이 봇의 현황 — 켜진 기능의 ✅ 표시와 실제 설정값. 그 기능이 쓰는 변수는 지우지 말라고도 알려 줍니다. 막의 본문과 숨겨 둔 글은 싣지 않습니다
· 대화에 나온 기능의 규격 — 말을 꺼낸 기능의 상세 규칙만, 최근 것부터 셋까지

시스템 기능이 맞는 일은 그 기능을 먼저 권합니다. 그래도 액션으로 하겠다고 하면 그대로 따릅니다.

제보에는 이런 말도 있었습니다. "대화에서 안 된다고 하면 준비만 해 줄 줄 알았다." 그렇게 동작하도록 맞췄습니다.

먼저 알아 두실 점

작업본이 있는 봇에서 [🗂 정리해서 반영]과 ✨ 창작으로 넣을 수 있는 것은 여전히 변수 · 파생 변수 · 판정 · 이벤트 · 랜덤 이벤트 · 지시문 · 액션 · AI 허용 변수입니다. 상점·보드 같은 기능 자체는 각자의 탭에서 만듭니다.
작업본이 비어 있으면 봇을 통째로 만드는 길이라, 상점·보드·메신저·의뢰판까지 한 번에 넣을 수 있습니다.

상점을 예로 들면

1. 💬 대화에서 "사고팔게 하고 싶어" → 상점을 권하고, 지갑과 구매품 목록으로 쓸 변수를 짚어 줍니다
2. [🗂 정리해서 반영] → 없는 변수만 제안 상자에 올라오고, 상자의 💡에 어느 탭에서 무엇을 채울지 적혀 있습니다
3. [상점] 탭 → AI로 상점 만들기 → 대화에서 정한 내용을 적으면 규격대로 만들어 줍니다

· 다른 탭에도 같은 칸이 있습니다 — [보드] 탭 AI로 보드 만들기, [메신저] 탭 AI로 메신저 설정 만들기, [의뢰판] 탭 AI로 의뢰판 설정 만들기
· ✨ 창작에 "상점 만들어 줘"라고 쓰면 전에는 형식 오류로 처리되거나 액션으로 흉내 낸 결과가 왔습니다. 이제 안내를 그대로 보여 주고, 변경 계획 상자에도 💡로 표시합니다

[스샷: 💬 대화가 상점을 권하는 답, 또는 제안 상자의 💡 안내]

🔧 손질 같이 바뀐 것 v1.21

· 🧩 [상점] 카드 — 구매 액션 묶음 대신 시스템 상점을 만듭니다. 전제는 그대로입니다(돈으로 쓸 숫자 변수, 소지품으로 쓸 목록 변수). 전에 이 카드로 만든 액션은 건드리지 않습니다
· 🛠 봇 제작 — 🧩 심코어로 갈 것의 분류에 상점·보드·메신저·의뢰판이 생겼습니다. 전에는 액션이나 기타로 적을 수밖에 없었습니다
· 없는 탭을 가리키던 안내 — 패치가 거부될 때 [게시판] 탭, [에셋]으로 나오던 것을 실제 이름인 [보드] 탭, [에셋 관리자]로 고쳤습니다
