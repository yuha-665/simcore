## 공통 제약 — 아카라이브 에디터

- **`<style>` 블록을 못 쓴다.** 전부 인라인 `style="..."`
- `class=`도 쓰지 말 것 (에디터가 자기 클래스를 붙인다: `fr-fic fr-dii`)
- `<script>` 불가
- 쓸 수 있는 태그: `p` `div` `span` `strong` `b` `br` `pre` `blockquote` `code` `img` `a`
- 스샷은 한 글에 **20장까지**
- 유저가 붙여넣으면 에디터가 `&middot;` `&rarr;` `&mdash;` `&quot;` 로 엔티티화한다 (정상)

**쓰고 나면 반드시 태그 균형을 검사할 것.** 특히 `<strong><span>…</strong>` 처럼 교차 닫는 실수가 잦다.

```bash
node -e "
const s=require('fs').readFileSync(process.argv[1],'utf8');
const stack=[],errs=[];const VOID=new Set(['br','hr','img']);
let m;const re=/<(\/?)([a-zA-Z][a-zA-Z0-9]*)\b[^>]*?(\/?)>/g;
while((m=re.exec(s.replace(/<!--[\s\S]*?-->/g,'')))){const[,sl,t,sc]=m;
 if(VOID.has(t.toLowerCase())||sc)continue;
 if(sl){const top=stack.pop();if(top!==t)errs.push('</'+t+'> ≠ '+top);}else stack.push(t);}
if(stack.length)errs.push('안 닫힘: '+stack.join(','));
console.log(errs.length?'❌ '+errs.slice(0,3).join(' | '):'✅ 태그 정상');
" 파일.html
```

## 가이드 시리즈 현황

톤: 반말, "~함/~됨", 챗붕이 대상. **"어려운 건 AI한테 시키면 된다"가 시리즈의 전제** —
JSON 손편집을 시키는 순간 전제가 깨진다.

| 탄 | 내용 | 상태 |
|---|---|---|
| 1 | 설치 → 샘플 템플릿 [새로 만들기] → 설치/업데이트 | 게시됨 |
| 2 | 상태창 종류 / 변수 만들기(AI 규격) / 디자인(CSS 규격) / **AI 설정 허용 변수** | 게시됨 |
| 3 | 규칙·이벤트 (매 턴 자동 · 지시문 · 조건 이벤트 · 랜덤 · 진단 · JSON 탭) | 원고 완료 |
| 4 | 액션 | 원고 완료 |
| 5 | 명령 | 원고 완료 |
| 6 | 새 시작 (프리셋 · AI 최초설정) | 원고 완료 |
| 7 | mentions · 맥락 턴 수 · 보조 AI 지시 + 세이브/배포 | 원고 완료 (v0.42.1에서 액션 잠금 문단 추가) |
| 8 | 판정 (checks — 굴림·등급·실행 통로 3개·이점 패턴) | 원고 완료 |
| 9 | 갈림길 (choices — 만들기·타임아웃·동시 1개·문턱 패턴) | 원고 완료 |
| 10 | 에셋 팩 (감정 이미지 봇의 `{{assetlist}}` 통짜 덤프 대체 — 팩·칸 개념) | 원고 완료 |

**남은 것**: 2탄에 v0.38 `layout`(탭/아코디언/팝업) 문단 추가. 4탄은 v0.42.1에서 "범례는 눌러도
안 됨" 문단을 클릭 조작으로 교체했다 — 이미 게시했다면 그 부분만 수정 필요.

### 원고 관례
- 스샷 자리는 `<p>[스샷: 무엇]</p>` 로 표시 → 유저가 이미지로 교체.
  **⚠ 유저가 이미지만 넣고 자리표시자 줄을 안 지우는 사고가 있었다. 넘길 때 같이 말할 것**
- 각 탄은 "0. 왜 필요한가"로 열고 "정리" 블록으로 닫는다
- 예시는 **반드시 실제 템플릿 값**을 쓴다 ([templates.md](templates.md))
- UI 라벨은 **반드시 코드에서 확인**한다 ([editor.md](editor.md))

## 배포 안내 (봇 제작자가 유저에게 알려야 할 것)

1. SimCore 플러그인을 먼저 설치 (없으면 상태창이 아예 안 뜸)
2. 봇에서 **[현재 캐릭터에 설치/업데이트]** 한 번 — 카드에 스키마가 실려 와도 이 버튼은 눌러야 한다
3. 새 채팅 시작 **전에** [새 시작]에서 프리셋 고르기
4. 보조 모델이 막힌 환경이면 **[루아 브리지 설치/갱신]** — 되는지는 [보조 모델 연결 테스트]로 확인

스키마를 고쳤으면 브리지도 다시 눌러 갱신해야 한다(불일치면 봇 편집 화면이 경고).
