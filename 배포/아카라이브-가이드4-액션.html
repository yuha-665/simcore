0. 우상단에 뜬 그 버튼 정체


1탄에서 템플릿 깔고 채팅 시작했으면 화면 우상단에 버튼이 몇 개 떠 있었을 거임.


[스샷: 채팅 화면 우상단 액션 버튼들]


그게 액션임. 템플릿에 이미 다 들어있어서 아무것도 안 했는데 생긴 거임. (RPG 2개, 서바이벌·정치 6개, 버튜버는 8개 들어있음)


지금까지 배운 건 전부 서사를 따라가는 것이었음. AI가 글 쓰면 상태가 따라 바뀌고, 규칙이 매 턴 정산하고.


액션은 반대임. 유저가 먼저 판을 흔드는 것.


"나 이번 턴에 휴식할래"를 글로 써서 AI가 알아주길 기도하는 게 아니라, 버튼을 눌러서 확정시키는 거임. HP는 시스템이 정확히 채워주고, AI한테는 "쟤 휴식했다"고 통보가 들어감.



1. 액션 뜯어보기


봇 편집 > 액션 탭으로 들어가면 됨.


[스샷: 액션 탭 전체]


RPG 템플릿에 들어있는 실제 액션임.


id  rest

버튼 이름  🏕 휴식

모드  1회성  /  쿨다운 2

AI 전달문  [플레이어 액션] 모닥불을 피우고 휴식을 취한다.

효과  HP = min(hp + round(max_hp * 0.5), max_hp)

            MP = min(mp + round(max_mp * 0.5), max_mp)


효과 칸은 3탄에서 배운 거랑 완전히 똑같음. 왼쪽 변수, 오른쪽 식. AI 전달문도 3탄의 AI 통지랑 같은 역할임 — 다음 전송에 AI한테 실려 감.


즉 3탄 봤으면 새로 배울 게 버튼 이름 / 모드 / 쿨다운 / 사용 조건 네 개뿐임.



2. 버튼 이름은 이모지로 시작해라


이게 취향 문제가 아니라 거의 필수임.


우상단 버튼은 글리프 한 칸짜리라서 이름이 다 안 들어감. 그래서 라벨 맨 앞 이모지 하나만 버튼에 뜸.


🏕 휴식  →  버튼에 🏕  (O)

휴식  →  버튼에 "휴"  (X — 뭔지 알아보기 힘듦)


그럼 "🏕가 뭔지 어떻게 알아?" 싶을 텐데, 상태창 아래에 글리프랑 이름을 짝지은 범례가 같이 나옴.


[스샷: 상태창 아래 액션 범례]


범례도 눌러서 실행됨 (v0.42부터)


저 범례가 진짜 버튼임. 누르면 우상단 버튼과 똑같이 무장/해제됨. 글리프만 보고 헷갈릴 필요 없이 이름 달린 큰 버튼을 누르면 되는 거임.


처음 쓸 때 메인 화면 접근 권한을 묻는 창이 한 번 뜨는데, 허용해야 클릭이 켜짐. 거부해도 안 깨짐 — 그 경우엔 예전처럼 우상단 버튼으로 누르면 됨. 잠긴(🔒) 액션은 어느 쪽으로도 안 눌림.



3. 1회성 vs 지속형


여기가 제일 헷갈리는 부분인데, 공통점부터 알면 쉬움.


버튼을 눌러도 그 자리에서 바로 적용되는 게 아님.
일단 무장(ON) 상태가 되고, 다음 메시지를 보낼 때 효과가 들어감.


이건 둘 다 똑같음. 눌러놓고 채팅을 안 치면 아무 일도 안 일어남. 상태창 범례에 ✅ 발동 대기라고 뜨는 게 그 상태임.


잘못 눌렀으면 한 번 더 누르면 취소됨.


차이는 발동한 다음임.


1회성 (oneshot)  한 번 터지고 자동으로 꺼짐. 쿨다운도 이때 걸림

지속형 (hold)  끌 때까지 매 턴 계속 적용됨


지속형은 "정책"이나 "태세" 같은 거라고 생각하면 됨. 영지 템플릿에 있는 실제 예시:


🛡 순찰 강화  (지속형)

AI 전달문  [지속 정책] 병사들이 순찰을 강화하고 있다.

효과  금화 = gold - 20


켜두면 매 턴 금화가 20씩 빠짐. 치안은 좋아지는데 유지비가 계속 나가는 거임. 끄는 걸 잊으면 금고가 조용히 말라감 — 그게 의도된 설계고.


버튜버 템플릿의 🔴 풀타임 방송도 같은 구조임. 켜두면 방송 시간이 계속 늘지만 체력이 매 턴 4씩 깎임.



4. 쿨다운과 사용 조건


이 둘이 액션을 "그냥 치트 버튼"이 아니게 만드는 부분임. 안 걸면 유저가 휴식 버튼만 무한 연타해서 게임이 끝남.


- 쿨다운  한 번 쓰면 몇 턴 동안 못 씀. 휴식이 쿨 2면 두 턴에 한 번만
- 사용 조건  조건이 거짓이면 아예 잠김. 비우면 항상 사용 가능


RPG 템플릿의 회복약 액션이 좋은 예시임.


🧪 회복약 사용

사용 조건  has(inventory, '회복약')

효과  소지품에서 '회복약' 제거  /  HP = min(hp + 50, max_hp)


가방에 회복약이 없으면 버튼이 잠김(🔒). 그리고 쓰면 소지품에서 실제로 하나 사라짐. 없는 약을 먹는 일이 구조적으로 불가능해지는 거임.


못 쓰는 버튼을 누르면 왜 못 쓰는지 알려줌. 상태창 범례에도 사유가 같이 뜸.


[스샷: 잠긴 액션 🔒 또는 쿨다운 표시]



5. 이것도 AI한테 시키면 됨


2탄·3탄이랑 똑같음. 액션 탭 맨 위에 규격 내보내기가 있음.


[스샷: 액션 탭 맨 위 내보내기 버튼]


이 봇에 어울리는 액션 5개만 만들어줘. 쿨다운이랑 사용 조건도 같이 걸어주고, 지속형도 한두 개 섞어줘


받은 JSON 붙여넣고 [📥 가져오기] → [설치/업데이트]. 3탄이랑 똑같이 항목이 확 줄었다는 경고가 뜨면 [↩ 가져오기 되돌리기] 누르고 다시 요청하면 됨.



6. 액션 만들 때 감 잡는 법


몇 개나 넣어야 하나 싶으면 템플릿 참고하면 됨.


RPG 2개  /  미스터리·로맨스 3개  /  사업 4개

서바이벌·정치·TRPG 6개  /  버튜버 8개


유저가 매 턴 고민할 게 있으면 잘 만든 것이고, 누를 이유가 없거나 반대로 안 누르면 손해인 버튼 하나만 계속 누르게 되면 잘못 만든 거임.


후자는 🔬 진단이 잡아줌. 3탄에서 배운 그거임 — "한 번도 못 누르는 액션"이나 "눌렀을 때 오히려 손해인 버튼"을 실제로 굴려보고 알려줌. 액션 넣었으면 진단 한 번 더 돌려보셈.



정리


실행  화면 우상단 버튼 또는 상태창 범례 클릭 (v0.42부터 범례도 진짜 버튼)

공통  누르면 무장 ON → 다음 전송 때 발동. 한 번 더 누르면 취소

1회성  터지고 자동 OFF + 쿨다운

지속형  끌 때까지 매 턴 계속

버튼 이름  맨 앞 이모지가 곧 버튼 아이콘


여기까지 하면 유저가 판에 개입할 수단까지 생긴 거임.


근데 아직 하나 빠졌음 — AI가 값을 잘못 넣었을 때 고치는 방법. 그건 다음 탄에서.
