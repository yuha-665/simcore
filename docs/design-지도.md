# 🗺️ 지도 — 가 본 만큼 채워진다 (v1.23.0)

유저(2026-11-09): 교토 전도 스샷(분류 단추 전체·권력·유흥·영험·거리·교토 밖 / 좌표 위 마름모 핀 / 가장자리 이정표 ↑구라마 →에도 /
"현재 위치" / 누르면 아래 카드에 그곳의 사정)을 보여 주며 "심코어에도 이렇게 지도 그리는 기능 추가 가능한가" →
"새 모듈 map으로. 아틀리에 나쁘지 않네, 아니면 베리디아처럼 **지도를 완성해 가면서 채워지는 기믹**도 넣을 수 있음 활용도 높을 것 같고".

## 0. 그전에 있던 것

| 봇 | 지도 | 한계 |
|---|---|---|
| 얼헌 | 편성표 대장 템플릿 탭 + `{gates:tags:권역}` — 서울 5권역 격자 | 좌표 없음, 칸에 글자 |
| 아틀리에 | 공방 패널 둘째 탭 — 격 0~5 사다리, `{areas:tags:지형}` | 같은 것 + 지형 안 붙인 항목은 **조용히 빠짐** |
| 베리디아 | 탐사 지도 탭 — 방향마다 자원·지형·둥지 줄 | 줄 글 |

상태창(채팅 안)은 새니타이저가 `data-*`를 지우고 리수가 CSS를 한 번 더 읽어(v1.21.3) 상호작용 지도를 그리기 나쁘다.
**패널은 우리 iframe DOM**이라 클릭·data-*·인라인 좌표가 다 산다 → 게임 패널 7호로.

## 1. 원칙

- **새 저장소를 만들지 않는다** (달력과 같은 원칙). 현재 위치 = 기존 위치 변수(`locVar`), 들른 곳 = 평범한 list 변수(`seenVar`),
  찾아낸 곳 = 평범한 list 변수(`listVar`, "이름 (구역)"). 그래서 리롤·되감기·현황 탭 손수정·조건식이 공짜로 따라온다.
  예약 키(`map_*`)를 만들지 않은 이유: 예약 키는 검증 충돌·reconcile·현황 표시를 따로 챙겨야 하고, 조건식은 `count(visited)`로 이미 된다.
- **숫자는 시스템** — 발자취는 보조 AI가 아니라 **정산이 적는다** (outputPhase 8.92: 이벤트·액션이 옮긴 위치까지 다 끝난 뒤,
  체크포인트 저장보다 먼저 — 저장이 그 턴의 발자취를 담는다). 보조 allow에 안 넣어도 된다.
- **꽉 찬 발자취는 밀지 않는다** — 오래된 발자취를 밀어내면 지도가 도로 안개에 덮인다. 대신 검증이 maxItems < 장소+구역 수를 경고.
- **버리지 않고 알린다** — 구역을 못 찾은 찾아낸 곳은 "자리를 못 찾은 곳"으로 지도 아래에 (옛 `{목록:tags:구역}`은 조용히 빠졌다).
- **그림 한 벌** — `mapView`(재료)·`renderMapHtml`(HTML)·`MAP_CSS`(기본 모양)가 코어에 산다. 패널과 편집기 미리보기가 같은 그림을 쓴다.

## 2. 모양

```js
map: {
  label: '교토 전도', icon: '🗺️', ratio: 1, bg: '지도',          // bg = 카드 에셋 이름 (선택)
  locVar: 'location', seenVar: 'visited', listVar: 'finds', fog: true,
  categories: [{ label: '권력', color: '#b3392f' }, { label: '유흥' }],
  zones:  [{ label: '가모가와 동쪽', x: 66, y: 8, w: 30, h: 78, known: true, desc: '…' }],
  places: [{ name: '기온', cat: '유흥', x: 80, y: 44, known: 'has(rumors, "기온")', rumor: '밤새 등불이…', desc: '…' }],
  exits:  [{ label: '에도', dir: 'e' }, { label: '오사카', dir: 'sw' }],
}
```

- 좌표 = 지도 크기에 대한 % — 화면 폭이 달라도 같은 자리.
- **known**: `true` 처음부터 / 식 = 참이면 / 없음 = 안개면 가 봐야(안개 없으면 보임). 안개 없는 지도에서도 식이 거짓이면 숨는다(조건부로 생기는 곳).
- 장소 상태 **seen**(발자취·지금 여기 → desc) / **known**(빈 마름모 "이름 ?" → rumor) / **hidden**(안 그림).
- 구역은 known·발자취·지금 여기·가 본 장소·찾아낸 핀으로 걷힌다. **소문만으로는 안 걷힌다** — 이름은 들었지만 땅은 아직 모른다.
- 지금 여기: 장소 name·alias → 찾아낸 곳 이름 → 구역 label·match. 안 맞으면 "📍 값 (지도 밖)". 구역이 지금 여기면 가운데 점 대신 **구역 이름표에 뱃지** (가운데엔 그 구역의 핀이 앉는다).

## 3. 찾아낸 곳의 자리

이름 해시로 섞은 칸 순서를 돈다 — 같은 이름은 늘 같은 자리. 비켜 앉는 것: 구역 이름표(+ 현재 위치 뱃지 자리) · 안에 든 작은 구역(들판 핀이 왕도 칸에
떨어지면 왕도 것처럼 보인다) · 다른 핀의 **이름표**(점끼리가 아니라 이름표끼리 겹친다). 첫 바퀴는 이름표까지 구역 안에 드는 자리만, 둘째 바퀴는 넘쳐도 된다.
칸이 다 차면 구역 가운데 근처에 조금씩 비켜 앉힌다(사라지는 것보다 겹치는 게 낫다).

- 실사고(구현 중): 처음엔 칸을 보폭으로 건너뛰며 돌았는데, 보폭이 칸 수와 약수를 나누면(25칸·보폭 5) 다섯 칸만 보고 "자리 없음"으로 떨어졌다 → 섞은 순서로.
- 좁은 화면: 이름표는 px, 자리는 %라 폭이 줄면 겹친다 → `.scm-frame` 컨테이너 쿼리 — 460px↓ 글자 축소, 380px↓ 찾아낸 곳은 점만(누르거나 지금 여기면 이름).

## 4. 편집기 [지도] 탭

01 기본 · 02 위치와 채워지는 지도([발자취 목록 만들기] 단추) · **03 미리보기 — 📍 찍기를 누르고 지도를 누르면 그 자리**(구역은 두 번: 한 모서리 → 맞은편),
[＋ 장소 찍어 넣기], "안개 걷은 모습"을 끄면 새 시작 직후 플레이어 시점 · 04 분류(이름을 바꾸면 장소·구역의 cat도 같이) · 05 구역 · 06 장소 · 07 이정표 · 08 CSS.
[지도 만들기]는 위치 선택지(enum) 이름으로 장소를 격자에 깔아 준다 — 찍기로 옮기면 된다. 탭 머리에 이 탭 몫 검증만.

검증 본문은 `map.validateMap`에 산다 — 규격서가 `validateSchema` 소스를 통째로 실어서, validate.js에 두면 최대 125.6KB(상한 128KB)였다. 옮긴 뒤 120.4KB.

AI 쪽: 탭 AI 창구(요청서에 위치·목록 변수와 예시), 전체 규격서 절, 기능 지도 표(`지도|약도|안개|map`), 켜진 기능 현황(장소 수만 — 목록은 길다),
변수 참조 색인, 변수 지우기 정리(연결 변수는 막고, 공개 조건 식은 빼냄). 패치 병합은 미지원 → `[지도] 탭`.

## 5. 아틀리에 적용

옛 공방 패널 지도 탭(격 사다리) → 지도 패널. 지어낸 약도(원작 지도 아님): 왕도를 가운데, 격이 높을수록 바깥.
- 구역 13 = 지형 12 + 왕도(들판 안에 든 작은 구역). 처음 걷힌 곳: 왕도·들판·프리겐. 나머지는 가 봐야(위치) 또는 채집지가 적혀야(areas).
- 장소 4 = 공방·별의 고치 카페·지방 도시(처음부터 아는 곳) + 왕도 뒷골목(`renown >= 100 or clues >= 1` — 뒷골목 이동 버튼과 같은 문턱에 소문으로).
- 분류 = 격 0~5 (거르면 "격 3 채집지 어디 있지"가 한눈에). 구역을 누르면 격·채집 목표치·나는 것(산지표)·계절 특산 — 옛 지도 탭의 정보 그대로.
- 발자취 `visited` 새 변수(init 공방·왕도, 24칸) — 보조 allow에 없다.
- 위치 선택지 17 = 구역 13 + 장소 4 — 전부 지도 위 (생성기 자체 검사).
