0. 첫 턴이 제일 어렵다


5탄까지 하면 봇은 완성임. 근데 시작할 때 문제가 하나 남음.


변수 시작값은 하나로 고정돼 있음. 근데 사람마다 원하는 시작이 다름.


"나는 밑바닥부터 기어올라가고 싶은데"

"나는 이미 자리 잡은 상태에서 시작하고 싶은데"


이걸 해결하는 게 새 시작 탭임. 두 가지가 들어있음.


시작 프리셋  유저가 버튼으로 고르는 난이도·배경 세트

AI 최초설정  첫 대화로 시작 상황을 정하는 것


둘 다 템플릿에 이미 들어있음. 프리셋은 템플릿마다 2~4개씩 있고, 최초설정도 blank 빼면 전부 켜져 있음.



1. 시작 프리셋


봇 편집 > 새 시작 탭임.


[스샷: 새 시작 탭 - 시작 프리셋 부분]


구조는 단순함. 이름 하나 + 바꿀 변수 목록. 서바이벌 템플릿 실물임.


초겨울 — 여유 있게 시작
기온 -12 / 석탄 500 / 식량 480 / 인원 45 / 희망 70


한겨울 — 이미 빠듯함
기온 -28 / 석탄 260 / 식량 230 / 인원 38 / 희망 50 / 불만 30


폐허 — 남은 게 거의 없음
기온 -34 / 석탄 120 / 식량 90 / 인원 22 / 환자 5 / 희망 30 / 불만 45


규칙·이벤트는 하나도 안 건드림. 숫자만 다르게 놓고 시작하는 거임. 그래서 같은 판인데 체감 난이도가 완전히 달라짐.


알아둘 것 두 개


- 여기 적은 변수만 바뀜. 안 적은 건 원래 시작값 그대로 감
- 값만 쓸 수 있음. 수식(gold * 2 같은 거)은 안 됨


RPG 템플릿은 이 성질을 잘 써먹은 예시임.


신참 모험가  (비어 있음 — 전부 기본 시작값)

베테랑 용병  레벨 5 / 금화 500 / 강철 장검 / 사슬 갑옷 / 회복약 2개 + 낡은 지도


기본 난이도는 아예 비워두는 게 정직함. 굳이 시작값을 또 적을 필요 없음.



2. ⚠ 난이도는 켜고 끄는 게 아니라 문턱을 미는 것


여기서 제일 많이 하는 실수임.


"쉬움에서는 역병 이벤트 빼야지" 하고 이벤트를 끄고 싶어지는데, 프리셋은 그걸 못 함. 변수 값만 바꿀 수 있으니까.


근데 이게 오히려 나음. 이벤트를 꺼버리면 쉬움 난이도에서는 300턴을 굴려도 그 이벤트를 영영 못 봄. 만들어 놓은 콘텐츠의 절반이 없는 셈이 됨.


대신 이렇게 하면 됨 — "시련" 같은 변수를 하나 만들어서 이벤트 조건에 섞는 것.


쉬움  시련 = 35    어려움  시련 = 85


역병 이벤트 조건  →  위생이 낮을수록, 시련이 높을수록 잘 터지게


이러면 쉬움에서도 역병은 옴. 대신 정말 관리를 놓쳤을 때만 옴. 어려움에서는 조금만 삐끗해도 옴. 이게 난이도지 콘텐츠 삭제가 아님.


좋은 일도 마찬가지임. 어려움에서 행운을 없애는 게 아니라, 걸릴 만큼 뭔가를 세워놔야 걸리게 만드는 거임.


난이도 이름 붙였으면 진단 돌려봐라


"쉬움"이라고 이름 붙였는데 실제로는 더 어려운 경우가 진짜 많음. 사람 눈으로는 절대 모름.


3탄에서 배운 🔬 진단이 이것도 잡아줌. 프리셋마다 실제로 굴려보고 버틴 턴 수를 재서 순서가 이름이랑 맞는지 알려줌.


참고로 쉬움과 어려움의 격차는 버티는 턴 수로 2배 안쪽이 무난함. 3배 넘어가면 어려움은 아무도 못 깨고 쉬움은 아무 일도 안 일어남.



3. AI 최초설정 (세션 0)


[스샷: 새 시작 탭 - AI 최초설정 부분]


프리셋이 미리 만들어둔 세트에서 고르는 것이라면, 최초설정은 첫 대화로 즉석에서 정하는 것임.


유저  나는 몰락한 귀족 가문 출신이고, 검보다 책이 익숙한 쪽으로 하고 싶어

AI  (대화로 시작 상황을 잡아준 뒤)

시스템  직업 = 학자 / 금화 = 80 / 무기 = 낡은 단검 / 지력 = 14 …


첫 턴 대화 내용을 읽고 보조 AI가 변수를 채워줌. 프리셋처럼 정해진 세트가 아니라 유저가 말한 대로 시작하는 거임.


칸이 세 개 있음.


- AI가 정할 수 있는 변수  체크박스로 고름. 여기 안 고른 건 AI가 못 정함
- 설정 대화 중 메인 AI에게 줄 지침  어떤 식으로 물어볼지
- 값 결정 가이드  보조 AI한테 "유저가 말한 건 그대로, 나머지는 배경에 어울리게" 같은 지시


전부 다 고르지 마셈


2탄 AI 설정 때랑 똑같은 원칙임. 날짜·주사위·진행 플래그 같은 건 빼야 함. 시작 시점에 AI가 날짜를 정해버리면 그 다음 계산이 다 어긋남.


템플릿들은 6~7개 정도만 열어놨음. 직업·장비·능력치·배경처럼 "캐릭터가 누구인가"에 해당하는 것들임.



4. 유저 입장에서는 이렇게 보임


제작자 말고 플레이하는 사람은 이걸 어디서 보냐면 — 플러그인 패널 첫 화면 [새 시작]임.


[스샷: 패널 새 시작 화면 - 프리셋 버튼들]


여기 프리셋 버튼이 쭉 뜨고, 하나 누르면 그 값으로 세팅됨.


중요: 프리셋은 새 채팅 시작 전에 고르는 걸 권장함. 한참 진행하다 누르면 그동안 쌓인 값이 갈아엎어짐.


같은 화면 아래에 이런 것도 있음.


- 상태 변수 (수동 보정)  값을 직접 손으로 고치는 곳. 5탄의 /명령이 패널 안 열고 하는 버전이라면, 이건 패널에서 직접 하는 것
- 액션 무장  4탄의 액션을 패널에서 켜는 자리
- 상태 완전 초기화  스냅샷까지 전부 지움. 진짜 처음부터 다시 할 때만



5. 이것도 AI한테 시킬 수 있음


프리셋도 규격 내보내기가 있음. 다만 여기는 프리셋만 갈아끼움 — AI 최초설정 쪽 지침은 안 건드리니까 안심하고 써도 됨.


[스샷: 새 시작 탭 맨 위 내보내기 버튼]


이 봇에 난이도 프리셋 3개 만들어줘. 쉬움/보통/어려움으로, 이름은 분위기 살려서


받아서 [📥 가져오기] → [설치/업데이트] → 🔬 진단으로 순서 확인. 이 세 단계가 세트임.



정리


프리셋  미리 만든 세트에서 고름. 값만 바꿈, 수식 안 됨

난이도  이벤트를 끄는 게 아니라 문턱을 미는 것

최초설정  첫 대화로 즉석에서 정함. 고른 변수만 AI가 채움

확인  난이도 이름 붙였으면 🔬 진단으로 순서 검증


이제 봇이 시작부터 끝까지 굴러감. 마지막 편은 세이브랑 배포 — 만든 걸 남한테 넘기고, 상태를 백업하고, 다른 기기로 옮기는 방법임.
