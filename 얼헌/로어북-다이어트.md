# 얼헌 로어북 다이어트 — 심코어 적용 시 정리 목록

원본 로어북 123항목(총 291K자) 중 심코어가 대체하는 것을 정리한다.
단계별로 지우는 시점이 다르다 — **P1 적용 시점에는 P1 열만 지운다.**

## P1에서 삭제 (헌터-신안.json이 대체)

| 항목 | 크기 | 대체처 |
|---|---|---|
| 상태창 | 6.7K자 | statusUI + 변수·파생 (EXP/최대치 공식은 derived) |
| 시스템 메시지 | 4.8K자 | promptState.systemGuide (`[시스템] …` 연출 지침) + 심코어 통지 |
| 측정 불가 방지 | 1.7K자 | directive `no_unmeasurable` 한 줄 |

같이 제거:
- **루아 통째** (`얼헌 루아.txt`의 트리거) — 상태창 생성(processStatusWindow)·설정 패널 토글·
  NPC 감지(processCharacterTokens) 전부. NPC 감지는 P2 전까지 공백이 생기므로
  **P2와 함께 제거**해도 된다 (상태창 로직만 먼저 죽이려면 status_model=0으로).
- **정규식 상태창 계열 12종**: 스탯 상태창 / 경량 상태창 / ## 상태창 찐빠 제거 / 쉼표·괄호·대괄호
  찐빠 제거 / 상태창 출력 제거 / 시스템 메시지 CSS·글자 크기 2종·색깔 정상화·찐빠 수정 2종.
- **설정 패널 계열 3종** (디스플레이 2 + 리퀘스트) — 기능 토글이 심코어 변수/프리셋으로 이동.
- 봇설정.txt의 채팅 시작변수 중 시스템 토글 17종 (NPC 48종 플래그는 P2까지 유지).

## 존치 (정적 설정 — 로어북이 잘하는 일)

세계관(게이트·스킬·알터 스토어·직업·길드·헌터·경제/물가), 지역 6국, 아이템(마정석·단말기·
엘릭서·코인), 길드/세력 6종, 적대 세력 2종, 이계의 신격 6종, 헌터 마켓, NPC 개별 항목 48종.

⚠ 존치 항목 중 알터 스토어·코인은 심코어 `store_on`, 적대 세력 계열은 `faction_on`과 짝 —
원본 로어북의 `{{getvar::lore}}` 조건은 심코어 변수를 못 읽으므로(저장소가 다름) 항목의
활성 조건을 로어북 키워드/상시로 재조정해야 한다 (P5 카드 정리에서 일괄).

## 에셋 정규식 (P5)
